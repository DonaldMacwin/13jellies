# 戯曲版（sagan_*.md）制作仕様

`content/articles/` にある学術記事 `2026-09-13-sN_tM.md`（全152本）を原典として、同じ内容を会話戯曲に書き直した `sagan_sN_tM.md` を併設する。本書はその制作規約であり、他端末・他AIサービスへそのまま渡して作業を継続できるよう、前提を省略せずに記す。

最終更新 2026-10-02（105本時点）。

## この文書の構成

本書は**規約だけ**を置く。「何を書いたか」「何の材料を使い切ったか」は分量が大きいので `PLAYS-LOG.md`（制作台帳）へ分けてある。

| | 内容 | 読むとき |
|---|---|---|
| **PLAYS.md**（本書） | 1 前提／2 一座と担当帯／3 配役／4 ファイル書式／5 作劇のルール／6 制作手順／7 検証／8 未決事項 | 書く前に毎回 |
| **PLAYS-LOG.md** | A 既存ファイル一覧（105本）／B 段ごとの設計メモ／C 使った人文知識の一覧（再利用禁止）／D 一括改訂の記録 | 座標を1つ決めたとき、材料を選ぶとき |

検証器は `chk.mjs`（プロジェクトルート）。詳細は §7。

## 1. 前提

### 1.1 サイトの構造

Astro の静的サイト。`content/articles/` 配下の Markdown を `src/lib/articles.ts` が読み、空間軸と時間軸の2本のスライダー（`src/Slider.tsx`）で記事を選ばせる。座標は frontmatter の `space_index`（0〜7）と `time_index`（0〜18）で決まる。

### 1.3 原典は変更しない

`2026-09-13-sN_tM.md` には一切手を入れない。戯曲版は別ファイルとして新規に作る。原典側の執筆規約は `content/articles/README.md` を参照。

### 1.4 published: false で退避する理由

`src/lib/articles.ts` は `content/articles/` 内の `.md` を `README.md` 以外すべて読み込み、`published` が未指定なら true として扱う。戯曲版は原典と同じ座標を持つため、`published: true` にするとスライダー上で原典の表示を奪う恐れがある。公開方式が決まるまで全ファイル `published: false` とする。

公開する場合は、同一座標に「論文版」と「戯曲版」を持たせて記事ページで切り替える仕組みをローダ側に作る必要がある。スライダー側の改修は不要の見込み。

## 3. 配役

両座とも登場人物は5人で、名前は共通。命名元はフランソワーズ・サガンの戯曲『草の中のピアノ（Un piano dans l'herbe）』だが、性格は原作に添わせていない。

### 3.1 サガン一座（人間）

避暑地の別荘に集まった旧知の仲間。全員45〜50歳。フランス人インテリらしくエスプリの利いた長話を好む皮肉屋、というのが共通の地色。

| 人物 | 設定 |
|---|---|
| モード（Maud） | 48歳。この別荘の女主人。かつて何人かの男を不幸にし、そのことを少しも後悔していない。会話のホスト役 |
| アンリ（Henri） | 49歳。哲学に詳しいというより、哲学者の逸話に詳しい。皮肉で話を打ち切る役 |
| ルイ（Louis） | 50歳。地質と気象に通じた元活動家。怒ることに疲れ、皮肉ることに落ち着いた。**時折くだらないアメリカンジョーク、アメリカ風の物の例え、不条理なブリティッシュ・ユーモアを口にし、モードとアンリに嘲笑される** |
| エドモン（Edmond） | 46歳。天文学者。妻と2人の子がいる。そのことをよく話題にするが、誰も聞いていない |
| イザベル（Isabelle） | 45歳。愛想がよく、学がない。そのかわり、誰も訊かない質問を訊く |

シルヴィアーヌ（Sylviane）とジャン（Jean）は舞台に登場せず、話題としてのみ現れる。2人の関係や不在の理由は各話で自由に設定してよい。

ルイの冗談に対する嘲笑は定型として使ってよい。二通りを使い分けている。

- アンリが理屈で潰す型: 「その説はぜひ学会で発表したまえ。誰も引用しないが、誰も反論できん」
- モードが絵として却下する型: 「ルイ、それは絵として成立していないわ」／「成立させるのは君の仕事ではない」

### 3.2 人ならざる者の一座

暫定の配役。名前はサガン一座と同一のものを流用している。記事の仕上がり次第でギリシア神の名などへ差し替える可能性があるため、本文中で人物の正体を確定させないこと。

| 人物 | 設定 |
|---|---|
| モード | 話のホスト役。**惑星と生命の「型」を集めていて、憶えているものと引き比べずにいられない。地球はその一点にすぎず、しかもお気に入りではない。遠い昔に一度だけこの星へ手を出したような口ぶりをすることがあるが、何をしたかは決して言わない** |
| アンリ | 皮肉屋 |
| ルイ | おちゃらけ・茶化し屋。**無限や確率など、細かな数字語りを担当する**（巨大な桁の意味を噛み砕く、桁の差を引き算してみせる、悪い比喩に落とす） |
| エドモン | おとなしめのいじられ役。割と人間贔屓 |
| イザベル | 気のいいおばさん気質 |

**五つとも、ほかのハビタブルゾーンに地球とはまるで違う進化を遂げた生き物がいることを知っている。地球の住人がそれを知らないことも知っている。また五つとも、地球の住人の見識の狭さにはとうに飽きている。それでも席を立たない。** この二つがあることで、モードとアンリが「地球でいま幅をきかせているあの連中は、こんな些末なことしか知らない」という角度から投げかけをしやすくなる。どちらも登場人物ブロックの末尾に明記する。

### 3.3 モードの扱い

進行役だけでは薄くなるため、二つの軸を重ねてある。サガン一座のモードが自由奔放な恋愛遍歴を持つことに対応する私的な軸である。

**蒐集家としての軸**は、74本すべてで反復できる言語習慣として使う。「この500万年はわたしの手持ちのなかでも珍しい型なの」「海を切って陸をつなぐ、という型は、ほかにも二つ憶えているわ」「管理人のいる家のほうが、たいてい早く終わるわ」。型でものを憶え、名前で憶えることを人間の趣味として見下す。座標が大きくなって比較対象が尽きる帯（s7 など）では、それ自体を彼女の限界として言わせる。「この大きさになると、わたしも比べるものが無いのよ」。

**一度だけ手を出したという軸**は、仄めかすだけで確定させない。「なぜこの星を何度も議題にするのか」とアンリに突かれて答えない、という形が基本。答えの代わりに、偶然が重なりすぎた事実へ話を逸らす。アンリが「……モード。」と呼びかけたまま次の話題へ移る、という間の取り方を標準とする。干渉できる存在だと本文で確定させないこと。正体を伏せる方針と揃える。

使い方の例。

- 生命の形を語る場面で「あの連中は自分の庭に生えているものを、宇宙の標準だと思っている」
- ハビタブルな条件を語る場面で「住める惑星の条件というものを、自分の家の間取りから逆算している」「参考にした物件が1軒しかないからな」
- 人間原理を語る場面で「炭素が無ければ観測者はいない」→「その一文で、彼らは自分の親戚だけを数え上げた」
- ただし、ほかの生命の具体像は描写しない。存在を知っていることだけを示し、中身は語らせない。正体を伏せる方針と揃える。

舞台設定の作法は以下。

- 場所も時刻も与えない。冒頭のト書きは `（場所はない。時刻もない。五つの声だけがある）`、幕切れは `（五つの声が、順に途切れる。幕）` を標準とする。
- 登場人物欄の末尾に「いずれも人ではない。五つとも、最後まで自分が何であるかを名乗らない」と置き、正体を伏せる。
- 時空論のスケールが大きいのでサガン風のシニックな文体に添わなくてよいが、**「人間というのはちんけで視野が狭く刹那的だ」という物言いの姿勢は維持する**。
- 人間を三人称で扱う。「あの連中」「あの子たち」「二足の連中」など。
- エドモンだけが人間をかばい、それをアンリとルイがいじる。この三段が毎回の摩擦になる。

## 4. ファイル書式

### 4.1 ファイル名と frontmatter

ファイル名は `sagan_sN_tM.md`。frontmatter は新規に書き起こす。

```yaml
---
title: "草の中の原子時計"
date: "2026-09-13T00:00:00Z"
slug: "sagan_s3_t9"
summary: "戯曲版: Space 3 / Time 9（今・半径5000km圏内）"
author: "未設定"
space_index: 3
space_unit: "km"
time_index: 9
published: false
---
```

- `slug` はファイル名（拡張子を除く）と一致させる。
- `space_index` / `time_index` / `space_unit` は原典と同値にする。
- `published` は必ず `false`。
- `author` は原典にならい `"未設定"` のままとする。

### 4.2 本文の骨格

```markdown
# 草の中の原子時計

<!--──ある八月の午後の、まだ確定していない現在について──-->

<!--
## 登場人物

モード　　48歳。この別荘の女主人。……

（中略）

ジャン　　この場にはいない。大西洋の上空にいる。
-->

## 第一場　セシウムの午後

（八月。午後。テラス。蝉の声。誰も何もしていない）

**モード**　ねえ、エドモン。いま何時？

**エドモン**　（腕時計を見て）4時12分。ただし、正確なところは来月にならないと分かりません。
```

- 表題は `# 草の中の◯◯` で統一する。『草の中のピアノ』のもじり。座標の核心にある物（原子時計、運河、日時計、手紙、地峡、椅子など）を選ぶ。
- 副題は `<!--──…──-->` でコメントアウトする。原典と同じ流儀。
- `## 登場人物` のブロック全体を `<!--` 〜 `-->` で囲む。読者には見せない。
- 場は `## 第一場　見出し` の形。数字は漢数字のままでよい（可読性の問題が出ていないため）。
- ト書きは全角括弧で独立行に置く。台詞中の動作は行頭の名前の直後に `（時計を見て）` の形で挿入する。
- 台詞行は `**名前**　本文`。名前を `**` で太字にし、直後は**全角スペース**。半角スペースは不可。
- 原典の記事に課している5つの整形ルール（句点のあとで改行、段落末 `<br><br><br>`、`**` の撤去など）は戯曲版には適用しない。台詞1行が1段落として読めるため。

### 4.3 数字の表記

**横書き表示のため、数量・年号・測定値はアラビア数字で書く。** 漢数字に開かない。

| 書く | 書かない |
|---|---|
| `1967年` `2022年11月15日` | 一九六七年 |
| `450台` `9,192,631,770周期` | 四百五十台 |
| `17ミリ秒` `8分19秒` `44分` | 十七ミリ秒 |
| `500万年` `138億年` `80億` | 五百万年 |
| `10の500乗` `5×10の25乗キロ` | 十の五百乗 |
| `1.62テラパーセク` `1.47` | 一・六二テラパーセク |
| `48歳` `2人の子` `450票` | 四十八歳 |

ただし慣用句・熟語は漢数字のままとする。`一つ` `二つ` `五つの声` `一度も` `一方` `一致` `一部` `唯一` `二酸化炭素` `二足の連中` `四半期` `三次元` `四次元` `第四紀` `千島海溝` `第一場` `五カ年計画` など。`数千キロ` `何百万年` `十数センチ` のように接頭辞が付くものもそのまま。

桁区切りは1万以上で `,` を入れる（`9,192,631,770`）。`万` `億` で割り切れる値は `500万年` `138億年` のように単位を残す。

### 4.4 その他の表記

- 固有名（探査機名、観測装置名、人名、地名、協定名、学説名など）は原典のものをすべて保持し、伏せない。
- 原典にある数値は落とさない。会話に載せにくい場合でも、誰かの台詞として必ず出す。
- 確定した事実と係争中の論点を文体で区別する。後者は「議論が続いている」「確定はしていません」などを明記する。

## 5. 作劇のルール

### 5.1 全体の方針

- **イザベルに毎回場面転換をさせない。**「素人質問 → 全員沈黙 → 称賛」の型は1本に多くて1回。発話比率は全体の13〜17%を目安とする。
- **アンリやルイの皮肉でストンと打ち切ってよい。** 場の終わりに落ちを付ける必要はない。
- **戯曲としての起承転結は求めていない。** 終場が悟りに着地しなくてよい。
- **メタな回数カウントは原則禁止。**「◯度目だ」「もう数えるのはやめよう」のように、**劇の進行そのものを登場人物が数える**型は使わない。ただし規則（6）（B）のエドモンによる反撃は例外とする（「『それでも』という言葉を三度お使いになりました」）。あれは劇の進行ではなく**相手の口癖**を数えており、記録係というエドモンの役どころの実演になっている。**例外は1本につき1回まで。**
- **同じ決め台詞を別ファイルで再利用しない。** 検証スクリプトで機械的に検出する。
- 場は7つ前後＋終場。1本あたり7,000〜9,000字（空白を除く）、台詞120〜210行が目安。
- 解説役が1人に集中する座標では、担当を意図的に配り直す。人外一座ではルイが数字語りを担うのが標準。

### 5.2 サガン一座で外してはいけないもの

原典の内容を会話へ移しただけでは、**大人が科学あそびをしているだけの台本**になる。2026-09-30 に `s0_t9` と `s1_t9` でその指摘を受けた。都会的でシニックでアンニュイな味を、次の4点で確保する。

1. **原典に無い人文知識を足してよい。** むしろ足さないと薄くなる。**文学・芸術・哲学からの引用や比喩も、積極的に用いてよい。** 詩句、小説の一節、絵画、思想史の逸話、語源。科学の記述を受けとめる側の言葉が無いと、台本が解説の羅列になる。下の使用例を参照のこと。
2. **私的な影を1本通す。** 不在のジャンとシルヴィアーヌ、モードの過去、エドモンの家庭、ルイが活動家をやめた経緯。科学の話題がそこへ折り返す瞬間を各話に2〜3回作る。
3. **その座標の物理を人間関係へ適用して終わる。** `s0_t9` なら「光ったのは見たわ。音はまだ来ていないことにしておきたいの」、`s1_t9` なら分水嶺の上に落ちた雨は風で決まる、という形。説明の比喩ではなく、登場人物自身の身の処し方として出す。
4. **倦怠から始めてよい。** 幕開けに沈黙や手持ち無沙汰を置くと、以降の理屈が遊びに見えなくなる。

`sagan_s0_t9.md`（草の中の雷鳴）はサイト入室後の最初のページにあたるため、この4点をとくに厚くしてある。新規に書くときの基準として参照すること。

### 5.3 規則の一覧

規則（1）〜（6）は、制作中に受けた指摘から順に足したものである。**番号は追加された順で、優先順位ではない。** 各規則の末尾に、出てきた経緯を残してある。同じ失敗を二度しないための記録なので消さないこと。

| | 規則 | 要点 | 出どころ |
|---|---|---|---|
| （1） | 別荘であることを本文で言い直す | 設定がコメント欄にしかないと、自宅にすり替わる | 2026-09-30 |
| （2） | 話者を移すときは台詞を書き直す | 名前の差し替えだけだと声が壊れる | 2026-09-30 |
| （3） | 5人は常に「いまの別荘」にいる | 未来の座標でも立ち位置を動かさない。余命を数えない | 2026-10-01 |
| （4） | 半径を本文で明示する | 1本に2〜4回、数値で言う | 2026-10-01 |
| （5） | 埋め草の禁止 | 拍ト書きとおうむ返しで字数を埋めない。削った跡にはエスプリの挿話を入れる | 2026-10-02 |
| （6） | 会話フォーマットの偏りを正す | ルイの冗談と、エドモン／イザベルの反撃を散りばめる | 2026-10-02 |

#### 規則（1）別荘であることを本文で言い直す

**（1）避暑地の別荘であることを、本文の中で毎回言い直す。** t10 の段で「長く住み続けているモードの自宅にみなが集まっている」へすり替わっているという指摘を受けた。原因は、別荘という設定がコメントアウトされた登場人物ブロックにしか書かれておらず、本文には一度も出ていなかったこと。次のいずれかを各話に最低2か所置く。

- 冒頭のト書きに季節を書く（`（八月。午後。別荘のテラス）`）。
- 滞在が断続的であることを台詞に含める。「20年**通って**いて」「この家を20年**持って**いて」とし、「20年**住んで**いて」とは書かない。
- 別荘であることが実際に効く具体を1つ出す（回覧板が夏に着いた日にまとめて渡される、前の持ち主が置いていった物がある、外灯を1つ外させた、など）。

#### 規則（2）話者を移すときは台詞を書き直す

**（2）話者を移すときは、台詞を書き直す。** 規則（1）と同じ 2026-09-30 の指摘の中で「地理の蘊蓄はエドモンからルイやアンリへ移せ」という依頼があった。**話者名の差し替えだけで済ませてはならない。** エドモンは「です・ます」、ルイとアンリは「だ・である」で、敬体のままの台詞をルイに移すと声が壊れる。加えて、差し替えると前後で同話者が連続することがある。移すときは、(a) 文体を書き直し、(b) 前後の隣接を確認し、(c) エドモンの持ち分が1割を下回っていないか確認する（下回ったら、その座標で彼が言うべき観測装置や数値の話を1〜2行足す）。

**分担の目安。** 地形・地質・気象・生態・統計の実数はルイ。制度・法律・歴史・思想はアンリ。観測装置・天体・暦・測定の精度はエドモン。ただし s4 以降は主題そのものが天文なので、エドモンが3割を超えるのは許容する。

#### 規則（3）5人は常に「いまの別荘」にいる

**（3）5人は常に「いまの別荘」にいる。未来の座標でも、立ち位置は現在から動かさない。** t11 以降は 2076 年や 500 万年後を扱うが、**5人がその時代にいるという前提を作らない。** 彼らは八月の避暑地で、気怠く未来の話をしているだけである。自分たちの余命・年齢を数える台詞は書かない（`s0_t11` にあった「わたしは98よ」「私は100だ」は削除した）。

「その時代には我々はいない」という感慨は、**第三者に預けるなら使ってよい**。`s4_t11` の「設計した人は、そのとき」「……おそらく、いません」は探査機を設計する人間の話なので残してある。自分たちの死を数え始めると、t12 以降の13段すべてが同じ感慨の反復になるため、そこは封じる。

#### 規則（4）半径を本文で明示する

**（4）半径を本文で明示する。** 「この圏内」「この寸法」「今日の座標」だけでは、読者はいま何キロの話をしているのか分からない。

- **各話の早い場（第一場か第二場）で、その座標の半径を一度、数値で言う。** 「5キロの円を描けば」「50キロ圏の話というのは」「今日は半径5000キロ、半球ぶんの話です」「334天文単位までの圏です」「今日の円は、半径5285万光年です」。
- そのあとは「この圏内」でもよいが、場が変わったら数値を言い直す。**1本の中で2〜4回は数値が出ている状態を目安にする。**
- 人外一座（s6・s7）は単位が実感を伴わないため、この規則はゆるくてよい。可視範囲との倍率（「あの連中の見える範囲の100倍より外だ」）のほうが効く。

#### 規則（5）埋め草の禁止

t12〜t14 で **「（少し置いて）」「（間）」「（短く）」「（ゆっくり）」の乱発と、イザベルの無内容なおうむ返し** が増えすぎた、という指摘を受けた。実測すると、`s0_t9` と `s7_t14` のあいだで台詞の平均字数が39.1→19.4字（半分）、「少し置いて」の密度が1.3→27.9/100行（21倍）になっていた。原因は三つある。

1. **検証スクリプトの「同一話者の連続禁止」が、台詞の製造装置になっていた。** エドモンが二文続けたいとき、それを黙らせる最も安い方法が「イザベルの相槌を挟む」か「（間）を入れる」だったため、規則を満たすために台詞が増えた。**この規則は撤廃した。** 同じ人物が二文続けて喋るのは普通のことである。
2. **重複台詞チェックが、凡庸な台詞を優遇していた。** 長くて特徴のある台詞は衝突しやすく書き直しを強いられる一方、「……500キロ。」のような数値のおうむ返しは数値が違うので永久に衝突しない。検証器が、憶えられる台詞を罰し、埋め草を無罪放免にしていた。
3. **原典の事実密度が t11 以降で落ちた。** 未来側の原典は「〜と考えられる」が増える。中身が減った分を間で埋めたため、`（少し置いて）` の位置が「言うことが無くなった箇所」の目印になっていた。

**削って終わりにしない。削った場所には、エスプリの挿話を入れる。** 科学の説明が一段落したところで、3〜6行の「人間の話」を差し込む。モードが色事・結婚・別れ・社交の比喩で受け、アンリが皮肉で落とし、ルイが茶化し、イザベルが内容のある素朴な問いを投げ、エドモンも参加する。口語的に（「〜でしょう？」「〜のよ」）、`？` と `『』` を使い、別荘・パリ・ワイン・引き出しといった生活の小道具を出す。1本につき2〜4箇所。**人外一座（s6・s7）は色事の比喩が使えないので、「人間を見物する側の軽口」と「正体を匂わせる台詞」で代替する。**

**数値の上限は `chk.mjs` が機械的に落とす。** 基準は t8〜t10 段（とくに `s0_t9`）の実測値である。

| 指標 | 上限／下限 | 趣旨 |
|---|---|---|
| 空ト書き率 | 12% 以下 | 「少し置いて／間／短く／ゆっくり／沈黙」など拍を刻むだけのもの。所作・口調の指定は数えない |
| 「少し置いて」 | 0.1/100行（事実上の全廃） | 21倍に膨れた元凶。`……` だけで足りる |
| 「間」「短く」「ゆっくり」 | 6.0／2.5／2.5 /100行 | 各ファイルで2箇所まで。残すなら、そのあとに続く台詞がいちばん長い箇所 |
| 台詞の平均字数 | 27字以上 | 人外一座は短い応酬が持ち味なので、地上側の33前後より低く取る |
| 10字以下の台詞 | 30% 以下 | |
| 40字以上の台詞 | 20% 以上 | エスプリの挿話が入っていれば自然に満たす |
| イザベル占有率 | 23% 以下 | おうむ返しで水増しすると、ここが真っ先に跳ねる |
| おうむ返し率 | 10% 以下 | 直前の台詞の語を8字以内で返しているイザベルの台詞の割合 |

**イザベルの役は「誰も訊かない質問を訊く」ことである。** おうむ返しは質問ではなく驚きの表明で、別物。数値を繰り返すだけの行は、内容のある問い（「1より小さいのは、どういうことなのかしら」）か、素朴な反応（「よりによって、蚊なのね」）に書き換える。ただし、**直後の台詞がその語を受けて答えている形（「爪。」→「爪だ。」、「一行も。」→「一行もだ。」）は意図した一撃なので残す。** 検証器もこの形は数に入れない。

#### 規則（6）会話フォーマットの偏り

**アンリの皮肉とモードのエスプリで締める型ばかりが頻出し、§3 の配役表に書いてあるのに実装されていない型が二つあった。** 次の二つを、サガン一座の各話に散りばめる。

**（A）ルイの出来の悪い冗談を、アンリかモードがくさす。** §3 に「時折、くだらない冗談や出来の悪い例え話を口にしては、モードとアンリに嘲笑される」とあるのに、実際にはルイが数字係に寄りすぎていた。型は次のとおり。

1. **場の主題から連想した、村の小話を一つ。** 「〜で思い出したが、うちの村では……」で入る。**40字以上の長台詞にすること**（検証器の長台詞率を下げないため、かつ、冗談は短いと冗談に見えない）。落ちは不条理寄り——誰も損をしないが何も解決しない——にする。
2. **アンリが刺す。** 「それは○○の話ではない、××の話だ」「例えより先に、例え話のほうが倒れたな」のように、**冗談の構造そのものを指摘する**形。
3. **ルイが半分だけ反論する。** 認めない。ただし言い張らない。
4. **モードが取り合わずに締める。** ト書きは「（取り合わずに）」。**ルイの冗談を無視したうえで、その小話を座標の主題へ折り返す**のが要点。ここで主題に接続しないと、ただの脱線になる。

**（B）アンリの皮肉、またはモードのエスプリに、エドモンかイザベルが反撃する／かぶせる。** 二人が受け身の相槌役に固定されると、五人芝居が三人芝居になる。型は次のとおり。

- **エドモンの反撃**は「（穏やかに）……〜と仰いましたが」で始め、**相手の言い方の構造を分解する**。感情では返さない。長台詞一つで論を立て、最後は短く引く。アンリが黙り、ルイが「（笑って）……」で場を収める。エドモンは本人を責めず、**観測・記録・数えたという言い方で逃げ道を残す**（「性格ではありません。観測です」）。
- **イザベルの反撃**は、**抽象の話をこの家の具体へ引き戻す**形にする（廊下の板の減り方、冬に使わない部屋、置いたままの皿、鉢の七つ目）。論破しない。具体を一つ置くだけで、アンリの一般論が宙に浮く。
- どちらの場合も、**アンリは負けを認めるか黙る**。認めさせない回を作ると、型が意地悪になる。

**検証器との兼ね合い。** 冗談と反撃は本質的に短い応酬になるので、そのまま足すと平均字数・長台詞率が落ち、短台詞率が上がる。**1ブロックにつき 40字以上の台詞を最低1本入れ、10字以下の台詞は1本までに抑える。** 平均字数が 27〜28 台の話（s4_t4、s4_t5、s2_t5、s5_t5 など）では、10字以下を1本も置かずに組む。

**適用状況。** サガン一座78本のうち、**s2・s3・s4・s5 の52本すべてに（A）と（B）を1組ずつ**入れた。s0・s1 は s0_t7、s0_t13、s1_t8、s1_t12 の4本に1組ずつとどめてある。**s2〜s5 のほうが会話の手触りが違って見えるのは意図した差である。**

### 5.4 人文知識の足し方

**使った材料は `PLAYS-LOG.md` §C に一覧がある。再利用はしない。** 同じ材料を二度使わないための台帳でもあるので、書いたら必ず追記する。

**同じ構図を別の座標で反復させるのは、署名として有効である。** 「古い測量に合わせて引いた線が、いまの対象と合っていない」という構図は、`s1_t9` のナポレオンの地籍と `s5_t9` の星座境界で意図的に響かせてある。読者がどの座標から入っても、二本目で気づく仕掛けになる。ただし台詞そのものの再利用は禁止（検証スクリプトが検出する）。

**引用の扱い。** 出典は正確に。ただし典拠を几帳面に示すのはアンリの柄ではないので、「パスカルが……と書いたな」程度に留め、誰かがすぐ茶化すか受け流す。名前を並べるだけの衒学にならないよう、必ず座標の主題へ折り返すこと。

## 6. 制作手順

0. **材料を押さえる。** `PLAYS-LOG.md` §C（使った人文知識）を引き、同じ `space_index` の既出ファイルを `grep` する。**s6・s7 はとくに消耗が早いので、必ず先に引く。** 候補が既出だった場合は、角度を変えるのではなく材料ごと差し替える。
1. 原典 `2026-09-13-sN_tM.md` を全文読む。要約で済ませない。
2. 隣接座標（前後の time_index、内外の space_index）の記事にも目を通し、内容の重複と参照関係を把握する。`PLAYS-LOG.md` §B に同じ段の設計メモがあれば読む。
3. 原典の序論・各章・結論を場に割り当てる。原典の主張を1つの劇的な仕掛け（発見、約束、不在の人物、物の不一致など）に翻訳する。
4. 執筆する。固有名と数値を落とさない。規則（4）（5）（6）を満たす形で組む。
5. `node chk.mjs tN` を通す。違反が出たら、閾値をゆるめるのではなく台詞を足す。
6. `node chk.mjs` を全体で通し、決め台詞がほかのファイルと重複していないか確認する。
7. `PLAYS-LOG.md` の §A（一覧）と §C（人文知識）に追記する。

## 7. 検証

**検証器はプロジェクトルートの `chk.mjs` に常設してある。**

```
node chk.mjs          # 全戯曲を検証
node chk.mjs t14      # t14 段だけ
node chk.mjs --stat   # 数値だけを一覧表示（SHOW_STAT=1 を付けると検証と同時に出る）
```

検査するのは次のとおり。

- **書式**: CR混入、キリル文字、LaTeX残り、H1がちょうど1個、コメントの閉じ忘れ、未知の話者名、太字名の直後が全角スペースか、括弧の全半角混在。
- **座標**: `slug` とファイル名の一致、`published: false`、`space_index` / `time_index` / `space_unit` の整合。
- **声**: エドモンの敬体とルイ・アンリの常体の混線、男性キャラの「あら」。
- **重複**: ファイルをまたいだ決め台詞の重複（先頭40字で照合。12字未満は対象外）。
- **埋め草**: 規則（5）の各上限。閾値は §5.3 規則（5）の表が正。

**「同一話者の連続」の検査は撤廃した。** 規則（5）に書いたとおり、あれが埋め草の製造装置になっていたためである。同じ人物が二文続けて喋るのは普通のことである。

### 7.1 機械で見ないもの

`chk.mjs` が通っても、次は手で見る。

- **漢数字の取りこぼし。** `[一二三四五六七八九〇十百千万億兆]` を検索し、§4.3 の慣用句リストに当たらないものが残っていないか。2026-10-02 に `s5_t10` の「二〇二〇年」が1件見つかっている。
- **`万` `億` `兆` が単独で 0 に潰れていないか**（`260万年` が `2600年` になるなど。一括置換で起きやすい）。
- **解説役の偏り。** イザベルの上限は §5.3 規則（5）の表（23%）が正。解説役が35%を超えていないかも見る。ただし s4 以降は主題が天文なので、エドモンが3割を超えるのは許容する。
- **おうむ返しの残り。** `chk.mjs` は率が上限内でも該当行を列挙する。t3・t15 段は0件で通したが、それ以前の段には1〜3行ずつ残っている。全話の初稿が揃ったあとの一括見直しで扱う。

### 7.2 一括改訂のしかた

多数のファイルへ同じ改訂を当てるときの手順。Windows 環境での失敗を踏まえた形にしてある。

1. **スクリプトはファイルとして書く。** コマンドラインに日本語リテラルを直接置くと、エンコーディングの不一致でマッチが空振りする。ヒアドキュメントで `.mjs` を書き出してから `node` で実行する。Perl を使う場合は `use utf8` と `'<:raw:encoding(UTF-8)'` を忘れない。
2. **正規表現を含むスクリプトはヒアドキュメントで書かない。** bash が `\*` などのバックスラッシュを食う。Write ツールか、正規表現を使わない素の文字列置換にする。
3. **アンカーは「既存の完全一致行」にする。** 行番号は挿入で動く。見出し行（`## 第七場　…`）は一意で短いので、挿入位置の目印に向いている。置換前に**出現回数が1かどうかを必ず確認**し、0回や2回以上ならその1件だけ飛ばして報告する。
4. **4本ずつ当てて、そのつど `chk.mjs` を通す。** まとめて当てると、どの改訂が閾値を割ったのか分からなくなる。
5. **閾値への影響を先に見積もる。** 短い応酬を足すと平均字数と長台詞率が落ち、短台詞率が上がる。`--stat` の現在値を見てから、足す台詞の字数を決める。
