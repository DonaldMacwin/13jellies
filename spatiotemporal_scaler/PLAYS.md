# 戯曲版（sagan_*.md）制作仕様

`content/articles/` にある学術記事 `2026-09-13-sN_tM.md`（全152本）を原典として、同じ内容を会話戯曲に書き直した `sagan_sN_tM.md` を併設する。本書はその制作規約であり、他端末・他AIサービスへそのまま渡して作業を継続できるよう、前提を省略せずに記す。

最終更新 2026-09-30。

## 1. 前提

### 1.1 サイトの構造

Astro の静的サイト。`content/articles/` 配下の Markdown を `src/lib/articles.ts` が読み、空間軸と時間軸の2本のスライダー（`src/Slider.tsx`）で記事を選ばせる。座標は frontmatter の `space_index`（0〜7）と `time_index`（0〜18）で決まる。

軸の定義は `src/Slider.tsx` が正。

### 1.3 原典は変更しない

`2026-09-13-sN_tM.md` には一切手を入れない。戯曲版は別ファイルとして新規に作る。原典側の執筆規約は `content/articles/README.md` を参照。

### 1.4 published: false で退避する理由

`src/lib/articles.ts` は `content/articles/` 内の `.md` を `README.md` 以外すべて読み込み、`published` が未指定なら true として扱う。戯曲版は原典と同じ座標を持つため、`published: true` にするとスライダー上で原典の表示を奪う恐れがある。公開方式が決まるまで全ファイル `published: false` とする。

公開する場合は、同一座標に「論文版」と「戯曲版」を持たせて記事ページで切り替える仕組みをローダ側に作る必要がある。スライダー側の改修は不要の見込み。

## 3. 配役

両座とも登場人物は5人で、名前は共通。命名元はフランソワーズ・サガンの戯曲『草の中のピアノ（Un piano dans l'herbe）』だが、性格は原作に添わせていない。

### 3.1 サガン一座（人間）

避暑地の別荘に集まった旧知の仲間。全員45〜50歳。フランス人インテリらしくエスプリの利いた長話を好む皮肉屋、というのが共通の地色。

| 人物 | 設定 |
|---|---|
| モード（Maud） | 48歳。この別荘の女主人。かつて何人かの男を不幸にし、そのことを少しも後悔していない。会話のホスト役 |
| アンリ（Henri） | 49歳。哲学に詳しいというより、哲学者の逸話に詳しい。皮肉で話を打ち切る役 |
| ルイ（Louis） | 50歳。地質と気象に通じた元活動家。怒ることに疲れ、皮肉ることに落ち着いた。**時折くだらないアメリカンジョーク、アメリカ風の物の例え、不条理なブリティッシュ・ユーモアを口にし、モードとアンリに嘲笑される** |
| エドモン（Edmond） | 46歳。天文学者。妻と2人の子がいる。そのことをよく話題にするが、誰も聞いていない |
| イザベル（Isabelle） | 45歳。愛想がよく、学がない。そのかわり、誰も訊かない質問を訊く |

シルヴィアーヌ（Sylviane）とジャン（Jean）は舞台に登場せず、話題としてのみ現れる。2人の関係や不在の理由は各話で自由に設定してよい。

ルイの冗談に対する嘲笑は定型として使ってよい。二通りを使い分けている。

- アンリが理屈で潰す型: 「その説はぜひ学会で発表したまえ。誰も引用しないが、誰も反論できん」
- モードが絵として却下する型: 「ルイ、それは絵として成立していないわ」／「成立させるのは君の仕事ではない」

### 3.2 人ならざる者の一座

暫定の配役。名前はサガン一座と同一のものを流用している。記事の仕上がり次第でギリシア神の名などへ差し替える可能性があるため、本文中で人物の正体を確定させないこと。

| 人物 | 設定 |
|---|---|
| モード | 話のホスト役。**惑星と生命の「型」を集めていて、憶えているものと引き比べずにいられない。地球はその一点にすぎず、しかもお気に入りではない。遠い昔に一度だけこの星へ手を出したような口ぶりをすることがあるが、何をしたかは決して言わない** |
| アンリ | 皮肉屋 |
| ルイ | おちゃらけ・茶化し屋。**無限や確率など、細かな数字語りを担当する**（巨大な桁の意味を噛み砕く、桁の差を引き算してみせる、悪い比喩に落とす） |
| エドモン | おとなしめのいじられ役。割と人間贔屓 |
| イザベル | 気のいいおばさん気質 |

**五つとも、ほかのハビタブルゾーンに地球とはまるで違う進化を遂げた生き物がいることを知っている。地球の住人がそれを知らないことも知っている。また五つとも、地球の住人の見識の狭さにはとうに飽きている。それでも席を立たない。** この二つがあることで、モードとアンリが「地球でいま幅をきかせているあの連中は、こんな些末なことしか知らない」という角度から投げかけをしやすくなる。どちらも登場人物ブロックの末尾に明記する。

### モードの扱い

進行役だけでは薄くなるため、二つの軸を重ねてある。サガン一座のモードが自由奔放な恋愛遍歴を持つことに対応する私的な軸である。

**蒐集家としての軸**は、74本すべてで反復できる言語習慣として使う。「この500万年はわたしの手持ちのなかでも珍しい型なの」「海を切って陸をつなぐ、という型は、ほかにも二つ憶えているわ」「管理人のいる家のほうが、たいてい早く終わるわ」。型でものを憶え、名前で憶えることを人間の趣味として見下す。座標が大きくなって比較対象が尽きる帯（s7 など）では、それ自体を彼女の限界として言わせる。「この大きさになると、わたしも比べるものが無いのよ」。

**一度だけ手を出したという軸**は、仄めかすだけで確定させない。「なぜこの星を何度も議題にするのか」とアンリに突かれて答えない、という形が基本。答えの代わりに、偶然が重なりすぎた事実へ話を逸らす。アンリが「……モード。」と呼びかけたまま次の話題へ移る、という間の取り方を標準とする。干渉できる存在だと本文で確定させないこと。正体を伏せる方針と揃える。

使い方の例。

- 生命の形を語る場面で「あの連中は自分の庭に生えているものを、宇宙の標準だと思っている」
- ハビタブルな条件を語る場面で「住める惑星の条件というものを、自分の家の間取りから逆算している」「参考にした物件が1軒しかないからな」
- 人間原理を語る場面で「炭素が無ければ観測者はいない」→「その一文で、彼らは自分の親戚だけを数え上げた」
- ただし、ほかの生命の具体像は描写しない。存在を知っていることだけを示し、中身は語らせない。正体を伏せる方針と揃える。

舞台設定の作法は以下。

- 場所も時刻も与えない。冒頭のト書きは `（場所はない。時刻もない。五つの声だけがある）`、幕切れは `（五つの声が、順に途切れる。幕）` を標準とする。
- 登場人物欄の末尾に「いずれも人ではない。五つとも、最後まで自分が何であるかを名乗らない」と置き、正体を伏せる。
- 時空論のスケールが大きいのでサガン風のシニックな文体に添わなくてよいが、**「人間というのはちんけで視野が狭く刹那的だ」という物言いの姿勢は維持する**。
- 人間を三人称で扱う。「あの連中」「あの子たち」「二足の連中」など。
- エドモンだけが人間をかばい、それをアンリとルイがいじる。この三段が毎回の摩擦になる。

## 4. ファイル書式

### 4.1 ファイル名と frontmatter

ファイル名は `sagan_sN_tM.md`。frontmatter は新規に書き起こす。

```yaml
---
title: "草の中の原子時計"
date: "2026-09-13T00:00:00Z"
slug: "sagan_s3_t9"
summary: "戯曲版: Space 3 / Time 9（今・半径5000km圏内）"
author: "未設定"
space_index: 3
space_unit: "km"
time_index: 9
published: false
---
```

- `slug` はファイル名（拡張子を除く）と一致させる。
- `space_index` / `time_index` / `space_unit` は原典と同値にする。
- `published` は必ず `false`。
- `author` は原典にならい `"未設定"` のままとする。

### 4.2 本文の骨格

```markdown
# 草の中の原子時計

<!--──ある八月の午後の、まだ確定していない現在について──-->

<!--
## 登場人物

モード　　48歳。この別荘の女主人。……

（中略）

ジャン　　この場にはいない。大西洋の上空にいる。
-->

## 第一場　セシウムの午後

（八月。午後。テラス。蝉の声。誰も何もしていない）

**モード**　ねえ、エドモン。いま何時？

**エドモン**　（腕時計を見て）4時12分。ただし、正確なところは来月にならないと分かりません。
```

- 表題は `# 草の中の◯◯` で統一する。『草の中のピアノ』のもじり。座標の核心にある物（原子時計、運河、日時計、手紙、地峡、椅子など）を選ぶ。
- 副題は `<!--──…──-->` でコメントアウトする。原典と同じ流儀。
- `## 登場人物` のブロック全体を `<!--` 〜 `-->` で囲む。読者には見せない。
- 場は `## 第一場　見出し` の形。数字は漢数字のままでよい（可読性の問題が出ていないため）。
- ト書きは全角括弧で独立行に置く。台詞中の動作は行頭の名前の直後に `（時計を見て）` の形で挿入する。
- 台詞行は `**名前**　本文`。名前を `**` で太字にし、直後は**全角スペース**。半角スペースは不可。
- 原典の記事に課している5つの整形ルール（句点のあとで改行、段落末 `<br><br><br>`、`**` の撤去など）は戯曲版には適用しない。台詞1行が1段落として読めるため。

### 4.3 数字の表記

**横書き表示のため、数量・年号・測定値はアラビア数字で書く。** 漢数字に開かない。

| 書く | 書かない |
|---|---|
| `1967年` `2022年11月15日` | 一九六七年 |
| `450台` `9,192,631,770周期` | 四百五十台 |
| `17ミリ秒` `8分19秒` `44分` | 十七ミリ秒 |
| `500万年` `138億年` `80億` | 五百万年 |
| `10の500乗` `5×10の25乗キロ` | 十の五百乗 |
| `1.62テラパーセク` `1.47` | 一・六二テラパーセク |
| `48歳` `2人の子` `450票` | 四十八歳 |

ただし慣用句・熟語は漢数字のままとする。`一つ` `二つ` `五つの声` `一度も` `一方` `一致` `一部` `唯一` `二酸化炭素` `二足の連中` `四半期` `三次元` `四次元` `第四紀` `千島海溝` `第一場` `五カ年計画` など。`数千キロ` `何百万年` `十数センチ` のように接頭辞が付くものもそのまま。

桁区切りは1万以上で `,` を入れる（`9,192,631,770`）。`万` `億` で割り切れる値は `500万年` `138億年` のように単位を残す。

### 4.4 その他の表記

- 固有名（探査機名、観測装置名、人名、地名、協定名、学説名など）は原典のものをすべて保持し、伏せない。
- 原典にある数値は落とさない。会話に載せにくい場合でも、誰かの台詞として必ず出す。
- 確定した事実と係争中の論点を文体で区別する。後者は「議論が続いている」「確定はしていません」などを明記する。

## 5. 作劇のルール

- **イザベルに毎回場面転換をさせない。**「素人質問 → 全員沈黙 → 称賛」の型は1本に多くて1回。発話比率は全体の13〜17%を目安とする。
- **アンリやルイの皮肉でストンと打ち切ってよい。** 場の終わりに落ちを付ける必要はない。
- **戯曲としての起承転結は求めていない。** 終場が悟りに着地しなくてよい。
- **メタな回数カウントは禁止。**「◯度目だ」「もう数えるのはやめよう」のように、登場人物が他の登場人物の発言回数を数える型は使わない。
- **同じ決め台詞を別ファイルで再利用しない。** 検証スクリプトで機械的に検出する。
- 場は7つ前後＋終場。1本あたり7,000〜9,000字（空白を除く）、台詞120〜210行が目安。
- 解説役が1人に集中する座標では、担当を意図的に配り直す。人外一座ではルイが数字語りを担うのが標準。

### サガン一座で外してはいけないもの

原典の内容を会話へ移しただけでは、**大人が科学あそびをしているだけの台本**になる。2026-09-30 に `s0_t9` と `s1_t9` でその指摘を受けた。都会的でシニックでアンニュイな味を、次の4点で確保する。

1. **原典に無い人文知識を足してよい。** むしろ足さないと薄くなる。**文学・芸術・哲学からの引用や比喩も、積極的に用いてよい。** 詩句、小説の一節、絵画、思想史の逸話、語源。科学の記述を受けとめる側の言葉が無いと、台本が解説の羅列になる。下の使用例を参照のこと。
2. **私的な影を1本通す。** 不在のジャンとシルヴィアーヌ、モードの過去、エドモンの家庭、ルイが活動家をやめた経緯。科学の話題がそこへ折り返す瞬間を各話に2〜3回作る。
3. **その座標の物理を人間関係へ適用して終わる。** `s0_t9` なら「光ったのは見たわ。音はまだ来ていないことにしておきたいの」、`s1_t9` なら分水嶺の上に落ちた雨は風で決まる、という形。説明の比喩ではなく、登場人物自身の身の処し方として出す。
4. **倦怠から始めてよい。** 幕開けに沈黙や手持ち無沙汰を置くと、以降の理屈が遊びに見えなくなる。

`sagan_s0_t9.md`（草の中の雷鳴）はサイト入室後の最初のページにあたるため、この4点をとくに厚くしてある。新規に書くときの基準として参照すること。

**引用の扱い。** 出典は正確に。ただし典拠を几帳面に示すのはアンリの柄ではないので、「パスカルが……と書いたな」程度に留め、誰かがすぐ茶化すか受け流す。名前を並べるだけの衒学にならないよう、必ず座標の主題へ折り返すこと。

## 6. 制作手順

1. 原典 `2026-09-13-sN_tM.md` を全文読む。要約で済ませない。
2. 隣接座標（前後の time_index、内外の space_index）の記事にも目を通し、内容の重複と参照関係を把握する。
3. 原典の序論・各章・結論を場に割り当てる。原典の主張を1つの劇的な仕掛け（発見、約束、不在の人物、物の不一致など）に翻訳する。
4. 執筆する。固有名と数値を落とさない。
5. 検証スクリプトを通す。
6. ファイル間で決め台詞が重複していないか確認する。

## 7. 検証

以下を機械的に確認する。プロジェクトルートに置いて `node` で実行する想定。

```js
import fs from 'node:fs';
import path from 'node:path';
import matter from 'gray-matter';
import {unified} from 'unified';
import remarkParse from 'remark-parse';
import remarkRehype from 'remark-rehype';
import rehypeStringify from 'rehype-stringify';

const dir = 'content/articles';
const files = fs.readdirSync(dir).filter(f => f.startsWith('sagan_')).sort();
const NAMES = ['モード','アンリ','ルイ','エドモン','イザベル','シルヴィアーヌ','ジャン'];
const proc = unified().use(remarkParse).use(remarkRehype, {allowDangerousHtml: true})
  .use(rehypeStringify, {allowDangerousHtml: true});
let errs = 0;
const E = (f, m) => { console.log(`  [ERR ] ${f}: ${m}`); errs++; };
const seen = new Map();

for (const f of files) {
  const raw = fs.readFileSync(path.join(dir, f), 'utf8');
  if (/\r/.test(raw)) E(f, 'CR 混入');
  if (/[Ѐ-ӿ]/.test(raw)) E(f, 'キリル文字混入');
  const fm = matter(raw), d = fm.data;
  const m0 = f.match(/^sagan_s(\d+)_t(\d+)\.md$/);
  if (d.slug !== f.replace(/\.md$/, '')) E(f, 'slug 不一致');
  if (d.published !== false) E(f, 'published が false でない');
  if (m0 && d.space_index !== +m0[1]) E(f, 'space_index 不一致');
  if (m0 && d.time_index !== +m0[2]) E(f, 'time_index 不一致');
  const body = fm.content, lines = body.split('\n');
  if ((body.match(/^# /gm) || []).length !== 1) E(f, 'H1 が 1 個でない');
  if ((body.match(/<!--/g) || []).length !== (body.match(/-->/g) || []).length) E(f, 'コメント未閉じ');
  let inC = false;
  for (let i = 0; i < lines.length; i++) {
    const l = lines[i];
    if (/^<!--/.test(l) && !/-->/.test(l)) { inC = true; continue; }
    if (inC) { if (/-->/.test(l)) inC = false; continue; }
    const m = l.match(/^\*\*(.+?)\*\*　/);
    if (m) {
      if (!NAMES.includes(m[1])) E(f, `未知の話者: ${m[1]} (L${i+1})`);
      const t = l.replace(/^\*\*.+?\*\*　/, '');
      if (t.length >= 16) {
        const k = t.slice(0, 40);
        if (seen.has(k) && seen.get(k) !== f) { E(f, `台詞が ${seen.get(k)} と重複 (L${i+1})`); }
        else seen.set(k, f);
      }
      continue;
    }
    for (const n of NAMES) if (l.startsWith(n + '　')) E(f, `未太字の台詞 (L${i+1})`);
    if (/^\*\*/.test(l)) E(f, `書式不正の太字行 (L${i+1})`);
    if (/^（.*\)$/.test(l) || /^\(.*）$/.test(l)) E(f, `括弧の全半角不一致 (L${i+1})`);
  }
  try { proc.processSync(body); } catch (e) { E(f, `HTML 変換失敗: ${e.message}`); }
}
console.log(errs === 0 ? '検証結果: エラー 0 件' : `検証結果: ${errs} 件`);
```

手で追加確認する項目。

- 漢数字の取りこぼし。`[一二三四五六七八九〇十百千万億兆]` を検索し、4.3 の慣用句リストに当たらないものが残っていないか。
- `万` `億` `兆` が単独で 0 に潰れていないか（`260万年` が `2600年` になるなど。変換を自動化する際に起きやすい）。
- 発話比率の偏り。イザベルが17%を超えていないか、解説役が35%を超えていないか。

### 一括改訂時の注意

多数のファイルへ同じ改訂を当てるときは、`use utf8` を書いた Perl スクリプトをファイルとして作り、`'<:raw:encoding(UTF-8)'` で読み書きする。コマンドラインに日本語リテラルを直接置くと、エンコーディングの不一致でマッチが空振りする（Windows 環境で再現）。
