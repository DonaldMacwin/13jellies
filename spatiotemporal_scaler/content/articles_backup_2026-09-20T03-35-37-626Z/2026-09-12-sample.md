# Spatiotemporal Scaler — サンプル記事

このページはローカルでスライダー表示と記事レイアウトを確認するためのサンプルです。`Slider` コンポーネントと `BaseLayout` により、時間・空間スライダーが固定された状態で本文がスクロールします。

## 使い方

- このファイルを保存したら、プロジェクトルートで開発サーバを起動して表示を確認してください。

```bash
npm run dev
```

ブラウザでページが表示されたら、画面左端の空間スライダーと上部の時間スライダーが見えるはずです。

## メタ情報について

- `space_index` / `time_index` はスライダーの tick 配列に対応する整数です。記事の選択にはこれらの値が使われます。
- 画像は `image` に外部 URL か `public` 配下のパスを指定してください。
