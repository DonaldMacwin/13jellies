# 直近過去5万年内・半径5km圏内の生態系：時空論的ミクロコスモスにおける時空間動態と生物群集の共進化

## 序論：五万年紀のタイムスケールと極小空間生態学の統合フレームワーク

地球物理学的・生物学的プロセスの長期的変遷と、特定空間における局所的生態系の動態を単一の統合的軸上で解明する「時空論」の試みにおいて、「直近過去5万年内」かつ「半径5km圏内」という時空間設定は、古環境学および古生態学におけるきわめて批評的な境界条件を提示する。直近過去500年および5000年を対象とした研究が、完新世の相対的安定期における歴史時代から先史時代への移行、ならびに文字・考古遺物主体の社会システムを論じるものであったのに対し、5万年（五万年紀）という時間は、海洋酸素同位体ステージ（MIS: Marine Isotope Stage）のMIS 3中期から最終氷期最盛期（LGM: Last Glacial Maximum, MIS 2）、そして後氷期である完新世（MIS 1）に至る、劇的な気候・環境の激変期を完全に入力系として包含する。

同時に、半径5km圏内（面積約$78.5\ \mathrm{km}^2$）という極小の空間解剖単位は、大型哺乳類の移動域（ホームレンジ）としては単一の行動圏あるいはその一部に過ぎない一方、土壌微生物、花粉、昆虫微化石、環境DNA（eDNA）等の微視的生物相にとっては、地形・微気候・水理条件に依存した高解像度な「生存の小宇宙（ミクロコスモス）」として機能する。本稿では、「古地質学」「古気候学」「古生物学」「古人類学」「考古学」の5つの学術カテゴリを包含・横断し、この半径5kmという微小な物理的基盤の上で、いかにして無機的な環境圧と有機的な生物群集（微生物から大型ファウナ、そしてホモ・サピエンスに至る）が相互作用し、生態系の構造と機能を転換させてきたかを論理的に解剖・統合する。

## １．古地質学・古気候学が規定する環境基盤の長期的変動

半径5km圏内における5万年間の生態系遷移を理解するうえでの物理的基盤は、**古地質学**的構造と**古気候学**的インプットの相互作用によって決定づけられる。過去5万年間は、北半球高緯度地域の氷床変動に連動したミリニアム（数千年）スケールの気候振動であるダンスガード・オシュガー（D-O）サイクルやハインリッヒ・イベントが頻発したMIS 3、全球的な極寒・乾燥期であるLGM（約2.6万〜1.9万年前）、遅氷期の温暖揺戻し（Bølling/Allerød間氷期）および急激な寒冷化（Younger Dryas期）、そして約1万1700年前以降の完新世温暖期という、振幅の極めて大きい気候変動系列によって特徴づけられる。

### (1) 地形発達・堆積様式と微小空間の地質構造
半径5km圏内という局所空間において、古気候変動は直接的に河川・斜面・湿地系における地質学的プロセスを駆動する。寒冷・乾燥期（MIS 2など）においては、機械的風化の促進と植物被覆の衰退に伴い、土砂供給量が著しく増大する。これにより、5km圏内の河谷部では盛んに側脱・荒廃が生じ、扇状地の拡大や粗粒な砂礫層の堆積が進む。また、周氷河現象に起因する崖錐（talus）の形成や、斜面でのソリフレクション（土流）運動が微地形を再編する。

一方、温暖・湿潤化が進行する完新世への移行期には、植物被覆の回復に伴って斜面物質の移動が定常化し、河川の下刻作用による河岸段丘の形成が進むとともに、低地部や旧河道には過湿な湿原環境が創出され、泥炭層の堆積が開始される。放射性炭素（${}^{14}\mathrm{C}$）年代測定および火山灰層（テフロクロノロジー）の対比は、これら幾重にも重なる堆積層の時系列を絶対年代の軸上に配置し、5km圏内の微地形がいつ、どのように形成されたかを精密に特定する鍵となる。

### (2) 微気候・水文環境のローカルな分岐
地球規模の気候変動は、半径5km圏内の斜面方位、標高差（仮に数テン〜数百メートルの比高が存在する場合）、風上・風下関係、湧水帯の存在などの局所的因子によって屈折され、多様な「微気候パッチ」へと不均一に翻訳される。例えば、LGM期における平均気温が現在より$6\sim8^\circ\mathrm{C}$低下した環境下においても、南向きの閉鎖的岩陰や低地湧水地帯においては、局所的な熱収支と水分供給が維持され、極端な寒冷・乾燥から退避した生物群集の「局所リフュジア（退避地）」として機能した可能性がある。古気候データの復元にあたっては、広域的な氷床コアや深海堆積物の酸素同位体比（$\delta^{18}\mathrm{O}$）シグナルを直接適用するのみならず、当該5km圏内の湖沼堆積物や洞窟生成物（スピーレオサム）の安定同位体比解析等を通じて、高精度な地域気候パラメータの抽出が不可欠となる。

## ２．古生物学・生態学が捉える生物群集の動態（微視的生態系から大型哺乳類まで）

**古生物学**的解析は、上述の古地質・古気候的枠組みの中で、多様な分類群がどのように群集構造を変化させ、一次生産から高次消費者に至る物質循環ネットワークを再構成したかを明らかにする。特に半径5km圏というミクロな空間においては、植物・昆虫・微生物といった高分解能な生物指標の解析が圧倒的な解像度をもたらす。

```
【過去5万年間の環境・生態系遷移モデル（極小空間解剖）】

 [ MIS 3 (50-26 ka) ]   寒冷・温暖の微振動（D-Oサイクル）
    ├─ 植生: 針葉樹・広葉樹混交林〜斑状の亜高山帯林
    ├─ 動物: ナウマンゾウ、ヤベオオツノジカ、中小型哺乳類
    └─ 人類: 後期旧石器時代・サピエンスの広域遊動（一時的進入）

 [ MIS 2 / LGM (26-19 ka) ]  極寒・乾燥期（最終氷期最盛期）
    ├─ 植生: 亜高山帯針葉樹林・草本ステップ（局所リフュジアの存在）
    ├─ 動物: 寒冷適応大型草食獣、微小哺乳類（タビネズミ類等）
    └─ 人類: 高密度拠点への集約、石器製作・石材獲得活動

 [ Late Glacial / YD (19-11.7 ka) ]  移行期・急激な環境動揺
    ├─ 植生: 針葉樹林の衰退と落葉広葉樹の先駆的拡大
    ├─ 動物: メガファウナの局所的絶滅・相変異
    └─ 人類: 縄文草創期/新石器文化の萌芽、土器の出現

 [ MIS 1 / Holocene (11.7 ka-現在) ]  温暖・湿潤期
    ├─ 植生: 落葉広葉樹林〜常緑広葉樹林の全域拡大・泥炭湿地形成
    ├─ 動物: ニホンジカ、イノシシ等の温帯森林相、土壌微小昆虫相の多様化
    └─ 人類: 定住的縄文集落・集約的土地利用・生態系への人工的介入
```

### (1) 土壌微生物相・微小生態系の分子古生物学的復元
5km圏内の堆積物層中に保存された環境DNA（sedimentary ancient DNA: sedaDNA）や、古細菌・細菌起源の膜脂質化合物（GDGTs: Glycerol Dialkyl Glycerol Tetraethers）の解析は、従来の目視可能な化石記録を補完し、微小生態系の挙動を可視化する。
氷期の寒冷・乾燥条件下の土壌においては、有機物分解速度の低下に伴い貧栄養状態に対応した不活発な細菌群集が優占するのに対し、暖期の到来とともに窒素固定細菌や線虫、菌根菌の活性化が急激に進行する。湿原や湖沼堆積物のコアサンプルから抽出される古脂質生体指標の炭素同位体比（$\delta^{13}\mathrm{C}$）および水素同位体比（$\delta\mathrm{D}$）は、5km圏内の一次生産者である陸上植物（$\mathrm{C}_3/\mathrm{C}_4$植物）の占有率の変化や、メタン生成古細菌の代謝活動の変遷をストイキオメトリックに記録している。

### (2) 植物群集の遷移と花粉・微小化石解析
植物相は生態系の骨格を成す。湖沼や湿地の堆積物から回収される花粉・胞子（Palynology）、および葉の表皮細胞に由来する植物珪酸体（Phytolith）の定量分析は、5km圏内の植生被覆の変遷を連続的に復元する。
*   **MIS 3〜MIS 2（氷期）**: トウヒ属（*Picea*）、モミ属（*Abies*）、カラマツ属（*Larix*）を中心とする亜高山帯針葉樹林や、ヨモギ属（*Artemisia*）、イネ科（Poaceae）を中心とする草本ステップが5km圏内を覆う。特にLGM期においては樹木被覆率が低下し、パッチ状の樹林と開放的な草地がモザイク状に同居する環境が形成された。
*   **完新世（暖期）**: 約1万1700年前を境に、コナラ属（*Quercus*）、ブナ属（*Fagus*）、カバノキ属（*Betula*）などの落葉広葉樹、さらに気候最適期（Holocene Climate Optimum）には照葉樹（カシ類・シイ類）が急速に5km圏内へ侵入・拡大する。これにより、林床への日照量、落葉層の質、果実生産量が根本的に変化し、一次消費者の構造を一変させた。

### (3) 昆虫類微化石による環境レジリエンスの定量的評価
甲虫目（Coleoptera）やユスリカ科（Chironomidae）の化石は、種ごとの生理的適応範囲（温度・水質・餌資源）が極めて狭いため、5km圏内の微小環境の変化を極めて敏感に反映する指標となる。特に糞食性甲虫（マグソコガネ類やダイコクコガネ類）の産出頻度は、その地域における大型哺乳類の移動・密度の直接的なプロキシ（代替指標）として機能する。LGM期における寒冷適応性甲虫相の優占から、完新世初頭における樹木依存性・腐植質依存性甲虫相への急激な置換は、微小空間における熱的適応と生態的ニッチの再編過程を明確に示す。

### (4) 大型哺乳類（メガファウナ）の行動圏と極小空間の利用
5万年前のMIS 3からLGMにかけて、この5km圏内にはナウマンゾウ（*Palaeoloxodon naumanni*）、ヤベオオツノジカ（*Sinomegaceros yabei*）、ヘラジカ（*Alces alces*）などの大型草食獣、およびそれを補食するハイドウグマ（*Ursus spelaeus*類）やヒグマ、オオカミなどの大型肉食獣が回遊していた。
半径5km圏内は、体重数トンのメガファウナにとっては「点」あるいは「通過ルート」に過ぎないが、湿地や水場、水塩の供給地（塩場）、避風性の高い谷あいは、彼らの集中的な採餌・飲水スポットとして機能した。彼らが踏み固めた径路（ゲームトレイル）や排泄物は、局所的な土壌の撹乱と養分濃縮（窒素・リンの局所的サイクリング）をもたらし、特定の草本植物の繁茂を促すという「生態系エンジニア」としての役割を果たしていた。しかし、Late Glacial期（約1.5万〜1.2万年前）におけるメガファウナの急激な衰退・局所的絶滅は、この大型消費者を介した物質循環系を不可逆的に切断することとなった。

## ３．古人類学・考古学が解明するホモ・サピエンスの介入と物質循環

5万年というタイムスケールの後半部（特に約4万〜3.5万年前以降）において、生態系の主要構成要素として不連続かつ決定的な影響を及ぼし始めるのが、**古人類学**的対象であるホモ・サピエンス（新人）の存在と、**考古学**的痕跡として抽出されるその行動体系である。

### (1) 後期旧石器時代の人類侵入と行動空間としての5km圏
アフリカに端を発しユーラシア東端に到達したホモ・サピエンスは、約4万年前のMIS 3において、この5km圏内へ初めて足を踏み入れた。古人類学的骨格化石の直接出土事例は稀少であるものの、遺跡から発掘される石器群（ナイフ形石器、細石刃など）の空間分布は、人類がこの極小空間をどのように認知し、利用していたかを雄弁に物語る。

旧石器時代の人類群集は、広大な領域を周遊する移動生活（バンド社会）を営んでおり、半径5km圏内は彼らの広域遊動領域（シーズン毎の行動域）の中の「特定の目的を持った局所拠点」として位置づけられる。例えば、5km圏内に良質な石材露頭（黒曜石やサヌカイト、頁岩など）が存在する場合、その空間は単なる生活の場を超えて、大規模な石器製作および資源獲得のノード（結節点）として機能した。また、遠望が利き動物群の移動を把握できる微高地や段丘崖線には狩猟の立待遺跡（タチマチ遺跡）が形成され、洞窟や岩陰は一時的な避難所（キャンプサイト）として利用された。

### (2) 人類の採餌戦略が生態系へ与えた影響
初期のホモ・サピエンスは、狩猟採集を通じて5km圏内の食物網（フードウェブ）の頂点に位置した。彼らによる大型草食獣への狩猟圧力（いわゆるオーバーキル仮説の局所的検証対象）や、植物性資源（堅果類や根茎類）の選択的採集は、標的となった生物種の繁殖成功度に直接的な影響を与えた。
さらに、人類による「火の定期的利用」は、自然発火による火災とは異なる周期で局所的な植生破壊と二次移行を促した。火の使用は草本ステップや二次林の維持を助け、結果として特定の草食獣（ニホンジカやイノシシ、あるいは旧石器時代の鹿類）の生息に適した環境を人工的に創出・維持する効果をもたらした。

```
【5km圏内における空間利用と資源・物質循環の変遷】

[ 旧石器時代 (〜12,000 BP) ]
 資源獲得: 精選された石材、大型・中型哺乳類、野生草本
 空間利用: 非定住・結節点利用（狩猟立待、石器製作現場、一時的避難場所）
 生態系影響: 局所的狩猟圧力、火の利用による部分的な微環境改変

[ 縄文/新石器時代 (12,000〜3,000 BP) ]
 資源獲得: 堅果類（ドングリ・クリ等）、温帯中小型獣、水生資源、土器用粘土
 空間利用: 半定住〜定住集落、貝塚・水場・埋葬領域の分化、里山環境の創出
 生態系影響: 有用樹種の選択的育成、有機廃棄物（貝塚）による局所的土壌アルカリ化

[ 弥生/歴史時代以降 (3,000 BP〜現在) ]
 資源獲得: 集約的イネ科作物（水稲）、木材、鉱物資源、水資源
 空間利用: 水田低地・集落高地の明確な二分、灌漑水路網・盛土・人工平坦化
 生態系影響: 原生林の激減と水田人工生態系の定着、外来種の侵入、自然の世俗化
```

### (3) 完新世における定住化と「里山生態系」の始原
約1万1700年前の完新世移行に伴い、縄文時代（あるいは新石器時代）の幕が開くと、半径5km圏内と人類との関係は劇的な構造変化を遂げる。土器の発明と堅果類のあく抜き処理技術の確立は、5km圏内の植物資源のキャリー能力（環境収容量）を飛躍的に飛翔させた。

人類は段丘上に比較的長期にわたる定住集落（竪穴住居群）を構え、住居周囲の森林を連続的に伐採・利用し始めた。これにより、完新世の極小空間には「手つかずの原生林」に代わり、萌芽更新能力の高いクリ（*Castanea crenata*）やコナラを中心とする、人間活動に依存した「二次林（里山構造の始原）」が形成される。集落周辺の廃棄場（貝塚や土坑群）には大量の有機物、土器片、骨灰が投棄され、局所的にリンやカルシウムが富栄養化した特殊な土壌環境が作られた。この人為的土壌変化は、特定の硝酸塩嗜好性植物やニッチな昆虫類の繁茂を促し、半径5km圏内の生物多様性を人工的にモザイク化させる要因となった。

## ４．総合的考察：５つの学術領域の交差点としての半径5km生態系

本稿において検討してきた5つの領域（古地質学、古気候学、古生物学、古人類学、考古学）は、それぞれ独立した分析手法を用いながらも、「半径5km圏内・5万年間」というミクロな時空間座標において強固に統合される。

## 結論：ミクロな空間地層が示す地球生態系の未来像

「直近過去5万年内・半径5km圏内」の生態系に関する統合的解析は、単なる一地方の自然史・先史史の復元にとどまらない。それは、地球規模の気候激変（MIS 3からLGM、完新世へ）という外部ショックに対し、有限の微小空間内に存在する地質・水理基盤と生物群集、そして人類がどのように不均一に適応し、レジリエンス（回復力）を発揮し、あるいは非可逆的な閾値（ティッピング・ポイント）を超えて移り変わってきたかを解剖する作業である。

5万年前の氷期における針葉樹林と大型ゾウ類の闊歩する風景から、LGMの極寒期における局所退避地での生命の維持、完新世の落葉広葉樹の繁茂と縄文集落による里山景観の形成、そして近現代における都市化・人工化に至るまで。この半径5km圏内に沈殿した地層、化石、遺物、そして環境DNAの断片は、自然と人類の長い対話の記録そのものである。我々が未来の地球環境変化や生態系の崩壊リスクに直面する今、この極小座標の中に蓄積された5万年の記憶を多角的に解読することこそが、持続可能な人為と自然の相生関係を再設計するための、最も確実な学術的基盤となるのである。
