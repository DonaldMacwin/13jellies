# 直近未来5000年内・半径5km圏内

## 序論：文字を持つ側の五千年を、未来へ折り返す

歴史地理学、文明論、考古学を主軸とし、これに地球惑星科学（固体・流体）、気候学、生態学を接続する統合学術カテゴリ「時空間（Spatiotemporal Studies）」において、「直近未来5000年内（2026年〜7026年）」かつ「半径5km圏内」という時空座標（Space 0 / Time 13）は、同じ長さを過去へ折り返せば、人類が文字を持ちはじめてから現在に至るまでの全期間にちょうど等しい。

直近過去5000年を扱った座標（Space 0 / Time 5）が、この徒歩圏における定住と耕地と信仰の全史を一望したのだとすれば、本稿はその鏡像を未来側に置くことになる。

同時にこの座標は、人間の身体的認知・歩行移動に収まる極小空間において、人為的インパルスの化学的・物理的残熱が完全に消退し、かつ旧近代産業文明の遺構がミクロな「テクノデポジット（人工地層・人工化石）」へと物理的に変性・固定化を完了する究極の静止相転移を定義する。<br><br><br>

空間軸である「半径5km」（面積約78.5平方キロメートル）は、人間の日常的・身体的な知覚および徒歩や極小モビリティによるアクセスが完結する「身体的極小空間」である。

これは、流域全体や主要平野を包括する半径50km圏（Space 1 / Time 13）のメゾ体系とは異なり、単一の小斜面、1本の活断層露頭、極小な谷頭凹地、あるいは過去の単一街区や巨大建造物遺構そのものが、物理的・生態学的分析の最小解像度となる現場である。<br><br><br>

一方、時間軸としての「直近未来5000年（半万年）」は、500年軸（Space 0 / Time 12）でみられた「温室効果の過渡的遅延応答に基づく新定常状態（Set Point）への着地」を超え、人間活動によって放出された温室効果ガスが深海炭酸塩溶解や風化反応を経て地球システムへ完全吸収・化学封入され、地球軌道要素（ミランコビッチ・サイクルの歳差運動等）に起因する長周期的な冷涼化・定常化トレンドへと再結合するスケールである。<br><br><br>

本稿の目的は、半径5kmというミクロな身体空間において、人間圏の営みが5000年をかけてどのように継承され、あるいは継承に失敗して地層化していくかを主題とし、それを支える固体地球・流体地球・生物圏の熱力学的平衡と架橋することにある。

この長さにおいて確実に言えることは多くない。

以下ではまず、人為圏の完全地層化と極小超定常社会の構造を論じ、その上で、それを取り巻く固体地球・流体地球・極小生物圏の動態を、それぞれ独立した記述の水準を保ったまま接続する。

## １．人為圏の完全地層化（テクノデポジット）と極小超定常社会の構造

### （１）近代・現代遺構の化石化：歴史地理・文化地理におけるミクロ層序

歴史地理および文化地理の領域において、5000年という時間は、20世紀から21世紀の近代産業文明が歴史的記憶の枠組みを脱し、物理的な地質学層序における「人類世地層（Anthropocene Strata）」として足元の地下数メートルに定着する時間である。<br><br><br>

かつて5km圏内に存在した高層建造物の鉄骨、コンクリート基礎、地下インフラ、高分子材料、人工合金は、5000年間にわたる地下水反応、風化、破砕、ならびに土砂被覆を経て、特異な鉱物相や「人工化石（Techno-fossils）」へと変性する。

グリーンランドの氷床コアには、共和政末期から帝政期のローマが銀を精錬した際に大気へ放出した鉛が、明瞭な濃度上昇として記録されており、その変動が当時の経済活動の盛衰と対応することまで読み取られている。

産業の規模が、二千年後の氷の中に数値として残っていたわけである。

なお、人新世を正式な地質年代として設定する提案は、2023年にカナダのクロフォード湖を模式地の候補としながら、2024年に国際層序委員会で否決された。

層としての実在と、区分としての承認とは別の問題である。

都市地理における過去の街路網や建築群の平面幾何構造は、地層内部の密度の違い、透過不連続面、あるいは元素濃縮帯（Techno-deposit）として地下に永久保存される。

### （２）人口・都市・行動の半万年相転移：ミクロ自然一体型超定常システム

人文学・社会科学的地理学において、5000年後の人間社会の空間配置は、500年軸で見られた集約型コンパクトノード（Space 0 / Time 12）すらも脱構築され、足元の自然基盤と完全に物理的・生態学的に一体化した「超定常型微小社会」の形態をとる。<br><br><br>

人口地理が描くのは、5km圏内の生態系一次生産量および環境収容力（Carrying Capacity）に合致した、変動幅の小さな極小定常人口（数十人から数百人規模）である。

この数値は、人間が安定した関係を維持しうる集団規模の推定値とも符合する。

ロビン・ダンバーが霊長類の新皮質の大きさと群れの規模の相関から外挿した約150という数は、狩猟採集民のバンド、軍隊の中隊、機能する村落の戸数など、時代と文化を越えて繰り返し現れる。

5km圏に数百人という配置は、全員が互いの顔と名を知りうる上限にあたる。<br><br><br>

都市地理および行動地理の観点では、大型の都市構造物という概念自体が消滅しており、人間圏は地殻変動やハザードのリスクから完全に免れた安定的微地形（不変的な台地や岩盤面）の上に、環境負荷ゼロの「超散在型極小住居（Micro-steady Habitat）」として配置されている。

人々の行動パターンは過剰な物理移動を伴わず、5km圏内の風土の波調に同期した持続可能な日常性で構成されている。

### （３）政治・行政・交通・産業地理の極小完全循環系

政治地理および行政地理の領域では、近代国家の人工的境界は消失し、半径5km圏内の単一の小流域や微地形境界に一致した「超局所自律圏（Micro-Local Autonomous Sphere）」が唯一の領域単位として機能している。

この機構は、5km圏内の水収支、土壌養分サイクル、および生態系バランスを半万年スケールで適正維持するガバナンスを備えている。

千年規模で機能してきた前例として、バリ島のスバックがある。

9世紀以来続くこの水利組織は、水源の寺院を頂点として、水田一枚ごとの取水順と作付け時期を儀礼の暦と一体に定めており、灌漑の配分と害虫の抑制を同時に達成していた。

1970年代の「緑の革命」に際して、この寺院暦を無視した二期作が推奨されると、かえって水不足と虫害が多発した。

5km圏の資源配分は、数学的最適化よりも、長期に検証された慣行のほうが堅牢でありうるという教訓である。<br><br><br>

交通地理および開発地理においては、かつての地上道路や鉄道路線は完全に撤去・自然還元されている。

生態系を分断する地上交通は存在せず、移動と物質輸送は地形の勾配や人間の歩行、ならびに分子レベルの局所循環システムによって無音で行われる。<br><br><br>

農業地理、工業地理、および商業地理の区分は解体・融合している。

食料獲得は自然生態系から持続可能な余剰分のみをわずかに採取する「極小高度共生アグリカルチャー」へ移行し、資材需要は地下のテクノデポジットからの微量元素の再回収と分子再組織化によって補われる。

過剰生産・大規模流通という行動様式は姿を消し、経済活動は物理的エネルギーと物質の完全な平衡循環として固定化されている。

## ２．固体地球・極小地盤の半万年積層と微地形・土壌・水文の最終変性

### （４）測地・プレート変動と地殻・マントルシミュレーションによる極小断層の累積変位

プレート変動および測地・固体地球変動の観点において、5000年という時間は半径5km圏内の極小地盤に明確かつ不可逆的な幾何学的変位を確定させる。

500年軸（Space 0 / Time 12）では特定の局所断層における1回の破砕と応力解放が中心的な議論であったが、5000年軸においては再来周期が数千年に及ぶ極小内陸活断層のほぼ全てが破砕サイクルを1〜数回完結させる。

これにより、5km圏内の特定の崖線や段丘崖には累計数メートルから十数メートルにおよぶ変位が直接刻み込まれる。

一回の地震が地表に何を残すかは、兵庫県淡路市の野島断層保存館が実物で示している。

1995年の兵庫県南部地震で生じた横ずれ1.2メートル、縦ずれ0.5メートルの地表地震断層が、あぜ道と生け垣の食い違いを含めて140メートルにわたりそのまま屋内保存されており、これが数千年に一度の頻度で繰り返された累積形が、段丘崖や断層崖の正体である。<br><br><br>

地殻・マントルシミュレーション、地球深部の物理、および地球深部物質の研究の知見を統合すると、広域的な造山運動に伴う応力が5km圏直下の微細な不連続面や粘弾性構造へ配分されるメカニズムが解明される。

上部マントルからの局所的な熱流束や流体移動の影響下で、5km圏内の露頭単位の岩盤強度は多世紀にわたり再編され、5000年を経て地盤は新たな静的応力平衡に落ち着く。

### （５）微地形・土壌・水文・災害系の統合と物理的完結

地殻の不可逆変位と気候系の長期安定は、5km圏内の微小な自然地理基盤を完全なる定常状態へ導く。

地形地理の領域では、5000年間に渡る斜面崩壊、土砂流出、ならびに極小谷底の埋積プロセスが進行し、侵食速度と風化生成物の供給速度が均衡する「微地形的動的平衡（Micro-geomorphic Equilibrium）」へ向かう。

過去側に同じ長さを折り返せば、この間に地形がどれほど動くかがわかる。

約6,000年前の縄文海進のピーク以降、木曽三川が運ぶ土砂によって濃尾平野の海岸線は南へ十数キロメートル前進し、当時は海であった名古屋の市街地の大半が陸になった。

5,000年とは、一つの平野が新たに生まれるに足る長さである。<br><br><br>

土壌地理においては、冷涼・定常気候下で風化が進行し、母岩から生成された粘土鉱物と有機物が深部まで緊密に結合した成熟したペドン（土壌体）が形成へ向かう。

火山灰を母材とする黒ボク土の場合、腐植に富む黒色のA層が1メートルに達するのに要する時間はおおむね数千年とされており、本稿の時間窓はその一巡にちょうど対応する。

ただし、厚さ数メートルという規模に達するには、なお一桁長い時間が要る。

水文地理および水循環の視点からは、降水パターンの定常化に伴い、5km圏内の浅層地下水脈と深部亀裂水系の流動速度・水質化学組成が一定値（Equilibrium State）へ収斂し、湧水点や不透水層境界の物理的配置が完全固定化される。<br><br><br>

災害地理の領域では、5000年間に発生した累積数千回の極小崩壊、局地豪雨、断層変位が時間軸上で平均化される。

局所的な「ハザード」という過渡的概念は消滅し、すべての物理現象は「微地形そのものを維持する不変的プロセス」として環境地理的基盤へ完全に吸収・統合される。

## ３．流体地球系の半万年再平衡と極小（ローカル）大気・海洋・気候系の固定

### （６）温室効果の完全消退と大気・海洋プロセスのミレニアム収斂

温暖化・寒冷化現象の観点において、2026年から7026年に至る5000年間は、20世紀から21世紀にかけて大気中へ過剰投入された二酸化炭素（CO₂）スパイクが、地球システムの超長期的化学フィードバック（海洋のアルカリ度補償および陸域の珪酸塩岩石風化反応）によって完全に封入・定着する時間枠である。<br><br><br>

大気物理および大気化学の解明によれば、大気中CO₂濃度は前産業革命期と同等水準へと回帰する方向に向かう。

ただし、この回帰は完了しない。

放出された炭素のうち二割から三割は千年後も大気中に残留し、珪酸塩岩の風化を介して最終的に除去されるまでには数十万年を要すると見積もられている。

本稿の5000年という窓は、深海の炭酸塩堆積物が溶解して海水のアルカリ度を回復させる過程がほぼ一巡する長さにあたり、そこまでで取り除かれるのは全体の八割前後にとどまる。

これにより、グローバル大気の極偏西風や熱帯収束帯の平均位置は自然変動の枠内へと収斂し、半径5km圏内のローカル大気における熱的過熱（ヒートアイランド現象等）は跡形もなく消滅する。<br><br><br>

ミクロな谷筋や斜面方位、局所的な日照差に起因する斜面風・谷風系、微小結露パターン、および局地性霧の発生（Micro-climate）は、熱力学的平衡のもとで極めて高い再現性をもって固定化される。<br><br><br>

海洋物理および海洋化学の観点では、全海洋の深層大循環が一周およそ1,500年という時定数で三度ほど巡航したことにより、海洋表層の熱・炭素過剰分は深海底堆積物とほぼ平衡に達する。

北大西洋で沈み込んだ水塊が、インド洋と太平洋を経て再び表層へ戻るまでの旅程が、本稿の時間窓のうちに三度完了する計算である。

ちなみに深海底から汲み上げられた水の放射性炭素年代は、太平洋北部で千数百年を示す。

いま深海にある水は、日本でいえば平安時代に海面と接していたものである。

5km圏内に含まれる極小な沿岸・ラグーン域では、海水酸性化のバッファリングが完了し、鉛直混合と栄養塩の動態が完全な季節周期性へと収斂する。

### （７）雪氷圏と沿岸微幾何学の最終静止点

雪氷圏および気候地理の視点からは、過去の温暖化ピーク期にもたらされた海面上昇が最終的な上限を打った後、大気CO₂低下と北半球高緯度の日射条件の変化（ミランコビッチ・サイクルの歳差運動等）に伴い、海面変化曲線は微減・静止傾向へと転ずる。<br><br><br>

半径5km圏内の沿岸境界においては、新海面水準（New Sea Level）のもとで波浪侵食と漂砂移動が完全平衡に達し、ミクロなサンドバー（砂州）、岩礁、ならびに湿地帯の幾何形状（Micro-coastal Geometry）が静止点に到達する。

## ４．極小生物圏の微小進化・種分化と「新原生自然」への昇華

### （８）5km圏内の隔離が生む微小進化と新固有種の定着

自然地理学と遺伝生態学が交差する生物地理の領域において、5000年という時間は、500年軸（Space 0 / Time 12）で見られた生物群落の遷移（Succession）や種組成の再編を超え、地理的隔離と局所適応による「微小進化（Microevolution）」が結実する時間スケールである。<br><br><br>

半径5km圏という極小空間であっても、隆起した断層崖、拡大した小河川、あるいは人工構造物の崩壊残骸によって物理的に分断された陸域生態系の小個体群は、5000年（数千世代）におよぶ世代交代を経て固有の遺伝的変異を固定化させる。

この速度が非現実的でないことは、直接観測された実例が示している。

ピーターとローズマリーのグラント夫妻は、ガラパゴス諸島の0.34平方キロメートルしかないダフネ・マヨール島で40年以上にわたりダーウィンフィンチの全個体を追跡し、干ばつの一年で嘴の平均サイズが有意に変化すること、そして2009年以降には交雑起源の集団がわずか三世代で生殖的に隔離された新系統として成立しうることを記録した。

本稿の空間半径より小さな島で、観測可能な時間内に進化が起きている。

過去の気候変動を生き抜いた微小昆虫、土壌微生物、小型爬虫類、草本植物などは、その5km圏固有の「超局所固有種（Micro-Endemic Species）」としての分類学的形質を獲得する。<br><br><br>

海域生態系においても同様に、水没した旧都市基盤や岩礁のミクロな空隙において、海洋生物が局所的な水温・塩分濃度差に適応し、独自の生態的ニッチ（生息場所）を完成させる。

### （９）ノベル・エコシステムの完全昇華と環境地理の到達点

環境地理の視点では、かつて人間活動によって改変された「ノベル・エコシステム（新開発生態系）」が、5000年間に及ぶ無人化と自然淘汰のプロセスを経て、人間活動の痕跡を内部に完全に組み込んだ「新・原生自然（Neo-Primal Nature）」へと昇華する。<br><br><br>

かつて外来種とされた生物群は在来種との共進化を経て食物網へ組み込まれ、最初からその5km圏に存在していたかのような調和を果たす。

人工構造物が生態系の基盤として完全に取り込まれる過程は、カンボジアのタ・プロームが視覚的に示している。

12世紀末に建立され、15世紀以降に放棄されたこの寺院では、ガジュマルやスポアンの巨木が回廊の屋根から根を垂らして石積みを抱え込み、いまでは根を切れば建物が崩れ、建物を外せば木が倒れるという相互依存の状態に達している。

数百年でこうなるのであれば、5000年後には、かつて構造物であったという事実そのものが判別しがたくなっているだろう。

自律的な炭素固定、土壌保持、水質浄化などの生態系サービスは、人間の介入なしに完全な永久機関として機能し続ける。

## 結論：継承と忘却の半万年

「直近未来5000年内・半径5km圏内（Space 0 / Time 13）」という時空座標系は、人類が産業文明期に極小空間へ与えた熱的・化学的・構造的擾乱が、5000年という半万年の歳月を経て、地球本来の物理・化学・生命プロセスへと完全に吸収・消化され、地下の地層（テクノデポジット）と表層の新原生自然へと二重に定着する「ミクロ相転移の完結」を定義する。

ここで生じる非対称が、この座標に固有の主題をなす。

人間の側が残したいと望むものと、実際に残るものとは一致しない。

何が残るかを決めるのは、残したいという意志ではなく、堆積環境と化学的安定性だからである。

過去5000年を参照すれば、少なくとも断絶の規模の見当はつく。

5000年前に話されていた言語のうち、現在まで直系で理解可能な形を保っているものは存在しない。

5000年前の集落の大半は、現在では堆積層の下にある。

未来側の5000年についても、同程度の断絶を想定しないことのほうが不自然である。

半万年後の受け手に何かを確実に伝えようとするなら、言語にも、媒体にも、制度の連続にも依存しない形式を選ばねばならない。<br><br><br>

広域流域スケールを扱った半径50km・5000年論（Space 1 / Time 13）や、身体空間の過渡的平衡を扱った半径5km・500年論（Space 0 / Time 12）に対し、本5000年/5km圏論は、人間が踏みしめるまさにその「足元の露頭・微地形・街区遺構」という極限の解像度において、断層変位の定着、温室効果の完全消退、ローカル気候の固定、超局所固有種の発生、そして人工構造物の化石化がいかなる幾何形状として定着するかを明瞭にした。<br><br><br>

固体地球の局所歪み解放、流体地球のミレニアム再平衡、生物圏の微小進化、そして人為圏の完全地層化──これら一連の動態は、「超局所時空統合学（Micro-Integrated Spatiotemporal Science）」の単一の理論枠組みの中にシームレスに統合される。

本稿が提示した包括的体系は、半万年先という深遠な未来において、人間の身近な極小地球空間が到達する最終的姿態を解明するための、不変の学術的基礎を提供するものである。
