# 直近未来5億年内・半径500km圏内の時空論
──メゾ空間枠（半径500km）を貫流する数万kmのプレートドリフトと造山・侵食サイクルの多重反復、局所地殻・マントル柱の熱化学相転移、および局所気候・極限環境下における生命圏の局所的閉塞と消滅──

## 序論：メゾ時空座標（5億年×半径500km）の学術的定義と「時空貫流モデル」

歴史学、地理学（人文・自然）、地球惑星科学（固体・流体）、気候学、ならびに天文学を包括する統合学術体系「時空間（Spatiotemporal Studies）」において、「直近未来5億年（$500\text{ Myr} = 5 \times 10^8\text{ 年}$）」という地質学的・天文学的超長周期タイムスケールと、「半径500km圏内（Space 2）」という地域・島弧スケールの局所空間が交差する座標系（Space 2 / Time 17）は、**「定置された領域的空間枠（半径500kmの円筒状時空体）を、地球表層・内部の質量、エネルギー、および地質構造が長周期で貫流・置換され続ける動的流動モデル」**を提示する。

全球規模を網羅的に扱う5000km圏（`s3_t17.md`）が「地球システム全体の終焉と超大陸の全体像」を描き出し、500万年軸（`s2_t16.md`）が「250〜400kmの同一プレート内変位と新造山帯の単一創出」を記述したのに対し、本座標系（Space 2 / Time 17）が解明すべき対象は、**半径500kmという特定空間枠内における、地球構造体の継続的な流出入と、複数回にわたる地質・気候・生物相の完全な置き換わり（完全構造置換）**である。

年間数センチメートルのプレート運動は、5億年間で累計1万〜4万キロメートル（$1 \times 10^4 \sim 4 \times 10^4\text{ km}$）におよぶ水平変位をもたらす。これは半径500km（直径1000km）の観測空間枠に対して10〜40倍に相当する距離である。したがって、現在この500km圏内に存在する地殻・地質体は数千万年以内に枠外へ流出し、まったく異なるプレートや陸塊、あるいは海洋地殻がこの空間枠を順次通過・進入・滞留することになる。

本稿では、時空間理論の学術体系に基づき、メゾ空間枠における固体地球の流出入動態、地殻・マントル柱の鉛直動態、局所気候（ローカル大気）・水循環の極限的相転移、ならびに生態系の局所的途絶と極限的微小化のプロセスを定量的・理論的に論じる。

## １．測地・固体地球変動、プレート変動、および地殻・マントルダイナミクス：メゾ空間枠の質量貫流と構造輪廻

### （1）数万kmの累積水平移動と地殻ブロックの完全流出入

**測地・固体地球変動**および**プレート変動**の観点において、半径500kmの観測領域は、5億年という時間窓の中で**完全に異なる地質体によって複数回占拠される**。

年間$2 \sim 8\text{ cm}$の速度で駆動するプレートテクトニクスは、$500\text{ Myr}$の間に$10,000 \sim 40,000\text{ km}$の累積水平変位を生む。直径$1000\text{ km}$の定置型メゾ空間枠を固定座標系として設定した場合、平均して$20 \sim 50\text{ Myr}$ごとに新たな島弧、背弧海盆、海嶺、あるいは微小陸塊がこの枠内に進入し、通過した後に枠外へと退出し去っていく。

現在この500km圏内に存在する地殻コンプレックス（例えば日本列島のような島弧−背弧系）は、遅くとも約$1\text{ 億年}$以内には空間枠外へ完全に退出し、太平洋あるいは大西洋の閉塞を経て形成される次世代の超大陸（アメイジアまたはパンゲア・ウルティマ）の遠方の一角へと移蔽される。

したがって、本時空座標における「地域の歴史・地理」は、単一の地質体の定常的な変容史ではなく、**「同一の空間座標を通過していった複数の異なるプレート・陸塊断片の流移動態史」**として定義し直される。

### （2）造山運動の多重サイクルと地殻・マントルシミュレーション

**造山運動**の地質学的時間スケールにおいて、単一の山脈の誕生から侵食・削剥を経て平原化（准平原化）に至るサイクルは、およそ$1\text{ 億年}$前後の期間で完結する。5億年という時間軸の中では、半径500km圏の空間枠内で**造山運動と地形の完全平原化（ペディプレネーション）が4〜5回繰り返される**。

**地殻・マントルシミュレーション**の数値モデルによれば、本空間枠を大陸同士の衝突帯（縫合線）が通過する際、積算隆起量数十キロメートルに達する激しい衝突型造山運動が発生し、標高$8000\text{ m}$級の超高山帯が一時的に創出される。しかし、地殻平衡（アイソスタシー）調整と重力弛緩（Gravitational Collapse）、および風化・侵食作用の力学抗衡により、山脈は$50 \sim 100\text{ Myr}$の周期で平坦な侵食シールド（古老楯状地）へと平原化される。

その後、超大陸の開裂（リフティング）や新たな沈み込み帯の到達に伴い、同一の空間枠内において再び新たな新造山帯の創出が開始される。この「山脈創出 $\to$ 重力弛緩・削剥 $\to$ 平野化 $\to$ 新規造山」という地質学的輪廻（orogenic cycle）の多重重畳が、メゾ時空（Space 2 / Time 17）の明確な構造的特徴である。

### （3）地球深部の物理と地球深部物質的研究：局所マントル柱の鉛直熱化学動態

**地球深部の物理**および**地球深部物質の研究**の知見に基づき、半径500kmの空間枠を鉛直方向に地表から地球中心まで延伸した「鉛直断層柱（マントル・コア柱）」を考察する。

5億年の間に、この直下マントル柱内を、沈み込んだ冷たいスラブの巨大集積体（メガ・スラブ）が下部マントルへ崩落する現象（スラブアバランシェ）が通過し、相補的に核−マントル境界（CMB）から高温の二次プルーム（熱的枝プルーム）が上昇・貫流する。

地殻底部のモホ面から深さ$660\text{ km}$のマントル遷移層に至る領域では、過渡的な相転移（オリビン $\to$ ワズレアイト $\to$ リングウッダイト $\to$ ブリッジマナイト＋フェロペリクレース）に伴う潜熱の発生と密度の不連続な変化が長周期で生じる。これにより、空間枠直下の地殻−マントル境界では、過渡的な巨大火成活動（Flood Basalt / 大型熔岩台地の局所形成）と地殻底部の超高圧熱変成作用が間歇的に引き起こされる。

## ２．大気・海洋・水循環・雪氷圏の物理化学的変容：局所気候（ローカル大気）の極限相転移

### （1）グローバル大気・大気物理・大気化学の変容とローカル大気の超乾燥・超高温化

$500\text{ Myr}$の時間軸において、主強制的因子である太陽光度の漸増（約$4 \sim 5\%$上昇）とケイ酸塩風化作用（$\text{CaSiO}_3 + \text{CO}_2 \to \text{CaCO}_3 + \text{SiO}_2$）の進行は大気組成を根本的に再編する。

**グローバル大気**レベルでの二酸化炭素（$\text{CO}_2$）濃度の極限的枯渇（$<10\text{ ppm}$）と、後述する陸上植物全滅に伴う酸素（$\text{O}_2$）濃度の低下、オゾン層（$\text{O}_3$）の完全崩壊は、**大気物理**および**大気化学**の光化学反応プロセスを変質させる。

この全域的背景のもとで、半径500km圏内の**ローカル大気**は、本空間枠が超大陸の内陸部に位置するか、あるいは外縁海に面しているかによって不連続な気候相転移を示す。

* **超大陸内陸期（約2.5〜3.5億年後）**：強烈な死の大陸性気候が局所空間を支配する。大気中の水蒸気量が極度に減少し、日中の地表気温は$60^\circ\text{C}$を超容、夜間は急激な放射冷却に見舞われる超乾燥砂漠気候が定着する。
* **超大陸分裂・湿潤温室移行期（約4〜5億年後）**：全球平均気温が$40 \sim 50^\circ\text{C}$に達すると、ローカル大気の熱力学的安定度が崩壊し、猛烈な過湿熱帯（Hothouse）または対流圏上部への水蒸気打ち上げ（Moist Greenhouse）の局所的拠点が形成される。

### （2）温暖化・寒冷化現象の極致と雪氷圏の完全喪失、メゾ水循環の枯渇

**温暖化・寒冷化現象**の長期的ダイナミクスにおいて、$500\text{ Myr}$の初期（遅くとも$1\text{ 億年}$以内）に地球上の**雪氷圏**は完全消滅する。

半径500km圏内がかつて極地域や高山帯に位置していたとしても、氷河、永久凍土、季節降雪といった雪氷圏の物理構成要素は地球上から永久に排除される。アルベド（反射率）の低下に伴う正のフィードバックは高緯度地域の熱環境を急変させ、全球的な南北気温勾配を大幅に平坦化させる。

**水循環**のメゾ構造も不可逆的に変容する。初期から中期にかけては、強烈な蒸発と局所的な豪雨を伴う短時間の過酷な水循環サイクルが展開されるが、$4 \sim 5\text{ 億年}$後の大気上層における水蒸気の光分解（$2\text{H}_2\text{O} + h\nu \to 2\text{H}_2 + \text{O}_2$）と水素の宇宙空間への熱的逃逸（Jeans Escape）の本格化に伴い、メゾ空間枠における有効水資源量（降水量から潜在蒸発量を差し引いた値）はマイナスへ傾斜し、陸域の水循環システムは不可逆な枯渇段階へと突入する。

### （3）海洋物理・海洋化学：局所海域の消滅・超塩分化とエバポライト沈殿の重畳

**海洋物理**および**海洋化学**の観点において、半径500km圏内に海域が含まれる場合、その水塊構造はプレート変位による海峡の開閉と海洋過熱化によって数億年単位で過酷な相転移を繰り返す。

超大陸の形成に伴い、本空間枠が浅海域（大陸棚）から隔絶された内陸閉塞海盆（メゾ内海）へと変貌した際、激しい蒸発作用によって海水の超塩分化（Hyper-salinity）が極限まで進行する。

これにより、局所海域では石膏（$\text{CaSO}_4\cdot2\text{H}_2\text{O}$）、岩塩（$\text{NaCl}$）、およびカリウム塩を含む巨大な蒸発岩（エバポライト）層序が数百メートルから数キロメートルの厚さで沈殿・重畳する。

その後、水温の絶対的増加（$40^\circ\text{C}$超）と溶存酸素の全滅に伴い、海洋物理的な鉛直混合は停止し、底層水は強烈な硫化水素に満ちた無酸素（Super-anoxic）還元環境へと固定化される。

## ３．生物圏の局所的閉塞と系統的絶滅：多細胞生命の解体と極限微生物への収束

### （1）陸域生態系の段階的壊滅と裸岩・砂漠化

**陸域生態系**における崩壊は、大気中$\text{CO}_2$枯渇に伴う光合成維持限界によって不可逆的に駆動される。

1. **第一段階（1〜2億年後）**：大気中$\text{CO}_2$が$150\text{ ppm}$を下回ることで、本空間枠内の高等植物相（$\text{C}_3$植物）が全滅し、森林生態系が消滅する。
2. **第二段階（3〜4億年後）**：$\text{CO}_2$が$10\text{ ppm}$を下回り、草本類（$\text{C}_4$植物）および耐乾燥植物（$\text{CAM}$植物）も絶滅する。

一次生産者の根絶は、半径500km圏内の陸上動物（昆虫、爬虫類、鳥類、哺乳類）の完全な連鎖絶滅をもたらす。植物の被覆と根系を失った陸域地表では土壌保持能力が瓦解し、強烈な物理的風化・侵食によって**土壌構造そのものが消滅**する。

本空間枠内の陸域景観は、先カンブリア時代のような有機物を含まない砂礫、裸岩、および強紫外下に晒された荒涼たる無生命砂漠へと完全退行する。

### （2）海域生態系の壊滅と微生物ドメインへの還元

**海域生態系**においても、過熱化、過塩分化、ならびに深刻な無酸素化が多細胞動物の生理的許容限界を完全に凌駕する。

$3 \sim 4\text{ 億年}$後までに、本空間枠内の海域からは魚類、軟体動物、節足動物、およびサンゴ類を含むすべての多細胞海洋生物が掃討される。

最終段階（$4 \sim 5\text{ 億年}$後）において、本メゾ空間枠内に定着し得る生命形態は、熱水噴出孔、地下深部岩石（Deep Biosphere）、あるいは超塩分閉塞湖底に局所化された**高度好熱性・好塩性の古細菌（Archaea）および細菌（Bacteria）**の単細胞フィルム（バイオフィルム／ストロマトライト構造）のみとなる。多様性に満ちた顕生代的な生態系は完全に解体され、太古代（Archean）初期の微生物世界へと不連続に還元される。

## ４．人為圏遺産の局所地質学的帰結：テクノストラタの超深部沈み込みと熱変成作用による解体

半径500km圏内に過去存在した人類世（Anthropocene）の都市構造物、人工鉱床、および産業廃棄物（コンクリート、高分子化合物、濃縮金属層）は、$500\text{ Myr}$の時間軸において**地殻変動による超深部沈み込みと熱変成作用**により物理化学的に完全に解体される。

1. **地殻短縮・沈み込みによる深部運搬**：プレート運動（1万〜4万kmの累積移動）に伴い、かつての沿岸・内陸メガシティが位置した地殻ブロックはマントル沈み込み帯へ引き込まれるか、大陸衝突帯の深部（地下10〜30km）へと圧入される。
2. **広域変成作用と溶融**：$200 \sim 600^\circ\text{C}$以上の温度および高圧下において、人為起源の複合材料は再結晶化し、ケイ酸塩、炭酸塩、および金属硫化物の変成鉱物集合体へと転換される。プラスチック等の合成高分子は熱分解・黒鉛化（グラファイト化）し、微細な炭素質鍵層として地層中に拡散する。
3. **同位体・地球化学的シグナルの減衰**：人工放射性同位体は半減期の経過に伴い完全に減衰し、かつて文明が存在した物理的・化学的証拠は、地質学的なバックグラウンドの揺らぎの中に完全に再吸収される。本空間枠内において、人類圏の過去の遺構は単なる鉱物相の幾何学的異常面（ミクロな不整合面）としてのみ極微小に痕跡を残すに過ぎない。

## 結論：半径500km・5億年軸における時空間理論の総括

「直近未来5億年内・半径500km圏内（Space 2 / Time 17）」における時空間理論は、固定されたメゾ空間枠を通過する地球物理学的質量・エネルギーの**「貫流・置換・不連続相転移」**の法則を明瞭に提示する。

| 学術領域 | 5億年（500 Myr）・半径500km圏（Space 2）における統合的現象 |
| :--- | :--- |
| **測地・固体地球変動・プレート変動** | 1万〜4万kmの累積プレート移動。空間枠に対する地殻ブロック・島弧・海嶺の多重な流出入と完全置換。 |
| **造山運動・地殻・マントルシミュレーション** | 造山・削剥・平原化サイクルの4〜5回に及ぶ反復。直下マントル柱におけるスラブアバランシェとプルーム上昇。 |
| **地球深部物理・地球深部物質の研究** | 地殻−マントル境界（モホ面）の熱化学相転移。過渡的巨大火成活動（Flood Basalt）と広域変成作用。 |
| **大気物理・大気化学・グローバル大気** | 太陽光度増加に伴う大気組成改変（$\text{CO}_2$枯渇、$\text{O}_2$急減、オゾン層崩壊）。 |
| **ローカル大気・温暖化・寒冷化現象** | 局所（ローカル）大気の超乾燥砂漠化または過熱湿潤化への極限移行。 |
| **雪氷圏・水循環** | 雪氷圏の完全消滅（1億年以内）。水素の宇宙逃逸に伴う陸域水循環の不可逆的枯渇と湿潤温室効果。 |
| **海洋物理・海洋化学** | 局所海域の閉塞・超塩分化と厚いエバポライト層序の沈殿。過熱・無酸素（Super-anoxic）環境の定着。 |
| **陸域生態系・海域生態系** | $\text{CO}_2$枯渇による植物相・土壌構造の消滅。多細胞生物の全滅と極限好熱・好塩古細菌群集への不連続還元。 |
| **人為圏遺産の帰結** | 人工建造物・テクノストラタの沈み込み・広域熱変成作用による完全溶融・再結晶化および地殻への再吸収。 |

全球規模の終焉を鳥瞰した5000km圏（`s3_t17.md`）に対し、本メゾ空間枠（500km圏）の時空論は、**「定置された特定の空間領域を切り取ったとき、そこに展開する地質体、気候体、生命圏がいかに流動的に入れ替わり、最終的に熱力学的・生物学的な極限状態へと収束していくか」**を記述する学術的枠組みを完成させる。

それは、歴史学、地理学、地球科学、気候学、天文学が交差する「時空間」という統合学術において、領域的観測枠における物質と生命の長周期ダイナミクスを解読するための不可欠な理論的標石となるのである。
