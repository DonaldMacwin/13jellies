# 記事ファイルの書き方

このフォルダでは、1記事につき1つの Markdown ファイルを置きます。

## 保存場所

- `content/articles/*.md`

## ファイル名ルール

- 推奨: `YYYY-MM-DD-slug.md`
- 例: `2026-09-13-s2_t7.md`

ファイル名は管理用です。ページ URL と記事識別には frontmatter の `slug` が使われます。
ただし運用上、ファイル名の `sX_tY` 部分と `slug` / `space_index` / `time_index` は一致させてください。

## URL ルール

- `slug: "s2_t7"` と書くと、URL は `/articles/s2_t7` になります。

## スライダー連動ルール

記事選択は frontmatter の `space_index` と `time_index` を使います。

- `space_index`: 空間スライダー位置（0〜7 の 8 段階）
- `time_index`: 時間スライダー位置（0〜18 の 19 段階）

トップページ `/` の初期表示は `space_index: 0` と `time_index: 9`（＝「今」）を基準にしています。

完全一致する記事があれば、その記事が表示されます。
完全一致がなければ「距離が最も近い記事」が表示されるため、8 × 19 = 152 本すべてを必ず用意する必要はありません。
ただし、全スライダー位置ごとに固有の記事を出したい場合は 152 本が必要です。

軸の定義は `src/Slider.tsx` の `spaceTicks` と `timeMagnitudes` が正です。
本 README と食い違った場合はソースを優先し、README を更新してください。

### `space_index` の対応

| index | スケール |
| --- | --- |
| 0 | `5×10^0 km` |
| 1 | `5×10^1 km` |
| 2 | `5×10^2 km` |
| 3 | `5×10^3 km` |
| 4 | `5×10^10 km` |
| 5 | `5×10^20 km` |
| 6 | `5×10^24 km` |
| 7 | `5×10^25 km` |

光年表記（`10^0 ly` など）は `src/Slider.tsx` でコメントアウトされており、現在は使用していません。

### `time_index` の対応

中央の `9` が「今」で、そこから過去側・未来側へ対称に広がります。

| index | 時点 | | index | 時点 |
| --- | --- | --- | --- | --- |
| 0 | `5×10^10年前` | | 10 | `5×10^0年後` |
| 1 | `5×10^8年前` | | 11 | `5×10^1年後` |
| 2 | `5×10^6年前` | | 12 | `5×10^2年後` |
| 3 | `5×10^5年前` | | 13 | `5×10^3年後` |
| 4 | `5×10^4年前` | | 14 | `5×10^4年後` |
| 5 | `5×10^3年前` | | 15 | `5×10^5年後` |
| 6 | `5×10^2年前` | | 16 | `5×10^6年後` |
| 7 | `5×10^1年前` | | 17 | `5×10^8年後` |
| 8 | `5×10^0年前` | | 18 | `5×10^10年後` |
| 9 | **`今`** | | | |

`5×10^12年`（5兆年）の両端は、宇宙年齢（約138億年）から大きく外れて記述が成立しないため廃止しました。

## frontmatter の必須項目

最低限、次を入れてください。

```yaml
---
title: "Space 2 / Time 7"
date: "2026-09-13T00:00:00Z"
slug: "s2_t7"
summary: "記事の短い概要"
author: "著者名"
space_index: 2
space_unit: "km"
time_index: 7
published: true
---
```

## frontmatter の任意項目

- `id`: 内部識別用の固定 ID。未指定なら `slug` を使います。
- `image`: 画像 URL。
- `image_alt`: 画像の代替テキスト。
- `categories`: カテゴリ配列。
- `tags`: タグ配列。

## 本文ルール

- frontmatter の下に通常の Markdown を書きます。
- 見出し、箇条書き、コードブロックはそのまま使えます。
- 文体は「だ・である調」で統一します。
- 他座標を参照するときは `（Space 2 / Time 8）` の形式で書きます。この表記はインデックス変更時に一括置換の対象になります。
- 生成ツール由来の `[cite: 1]` のような参照記法は残さないでください。

## サンプル

```md
---
title: "Space 2 / Time 7"
date: "2026-09-13T00:00:00Z"
slug: "s2_t7"
summary: "500年という窓が器械観測の起点を含むことを論じる。"
author: "著者名"
space_index: 2
space_unit: "km"
time_index: 7
published: true
---

# 直近過去500年内・半径500km圏内の時空論

本文を書く。
```
